# CHANGELOG — news-shorts

## 0.1.1 (2026-08-27) — 실전 검증 반영

「무릎건강」 키워드로 news-research → news-verify를 **실제로 완주**해 규칙의 실효성을 확인했다. 잘 작동한 것과 틀린 것이 함께 나왔고, 틀린 것 3건을 반영했다.

**검증에 쓴 소재**: RMD Open 2026-02-17 「Effectiveness of exercise therapy for osteoarthritis: an overview of systematic reviews and randomised controlled trials」(DOI 10.1136/rmdopen-2025-006275). 리뷰 5편·RCT 28편, 무릎 통증 위약 대비 평균차 −10.8(95% CI −19.1~−2.6), **GRADE 확실성 very low**, 저자 결론 "largely inconclusive".

### 확인된 것 (변경 없음)

- **관문 2 예외가 작동했다** — T1 원문(PMC 전문)을 직접 열어 확인한 수치가 단일 출처로 통과했다. v0.1.0 감사에서 "공적 통계가 영원히 1출처라 막힌다"고 지적된 문제가 실제로 해소돼 있었다
- **관문 3 절차가 실행 가능했다** — PubMed 페이지에서 Retracted/Erratum 배너 없음을 실제로 확인했다. "확인했다는 말만 만드는" 규칙이 아니었다

### 고친 것

**1. 강도 판정이 연구 설계만 보고 근거 확실성을 보지 않았다 (치명)**

E2 정의가 "체계적 문헌고찰·다수 RCT"라 위 논문은 **설계상 E2**로 올라갔다. 그런데 GRADE 확실성은 very low이고 저자 스스로 결론을 내리지 못했다고 밝혔다. `myth`의 "반박 근거는 E1~E2만" 규칙과 결합하면 **이 연구로 "운동은 소용없다"는 영상을 만들어도 통과한다** — 저자가 아니라고 하는데 플러그인이 허용하는 상태였다.

- `claim-rules.md` 4절 + `news-verify` 3단계에 **GRADE 확실성 우선 규칙** 신설: 원문에 확실성이 명시돼 있으면 **설계보다 우선**한다. low·very low → **강도 상한 `E3`** (설계가 overview여도)
- 저자가 결론에서 "inconclusive"·"uncertain"이라고 밝힌 카드는 **`근거부재`에 준해** 다룬다. 어떤 통념도 뒤집는 근거로 쓰지 않는다
- **저자보다 세게 말하지 않는다** — "의문을 제기한다"를 "뒤집혔다"로 옮기지 않는다
- 관문 5에 `GRADE 확실성` 확인 항목, 팩트 카드에 동명 필드 추가
- auditor에 "강도가 GRADE 확실성과 맞는가" FAIL 항목 추가

**2. 관문 5에 임상적 유의성(MCID)이 없었다 (중)**

절대/상대는 잡는데 **"그래서 사람이 체감할 만큼인가"**를 묻지 않았다. MD −10.8은 절대값이라 관문 5를 그냥 통과하지만 원문은 "clinically meaningful하지 않다"고 명시한다. 자막에 수치만 띄우면 출처 있는 오정보가 된다.

- `claim-rules.md` 3-4절 신설: **"통계적으로 유의"와 "실제로 의미 있다"는 다르다**
- 팩트 카드에 `임상적 유의성` 필드(충족 / 미달(원문 명시) / 미확인) 추가
- 원문이 미달이라고 밝히면 **수치와 그 사실을 같은 문장에** 넣는다 — 나레이션 필수(자막 전용 이관 금지)
- news-script 세 유형 공통 필수 항목, auditor 수치 해석 검수에 반영

**3. "E3면 myth를 만들지 않는다"가 소재를 통째로 버리게 했다 (중)**

브리프가 "통념을 깨는 새 연구가 E3면 만들지 않는다"고 못 박아, 4050에게 가치 있는 뉴스를 폐기하게 되어 있었다.

- `news-type-briefs.md` 3부 라우팅 변경: **버리지 않고 `issue`로 각도를 낮춘다** — "이런 연구가 나왔고, 아직 결론은 나지 않았다"까지만. 훅은 `H10`·`H6`을 쓰고 `H4`·`H8`은 쓰지 않으며, 제목에 "사실은"·"뒤집혔다"를 넣지 않는다. 현행 권고를 함께 전하고 "지금 바꿀 이유는 아직 없다"로 마무리한다
- news-script `myth` 절에 전환 규칙 + 산출물 머리에 전환 사유 기재 의무
- auditor에 "myth → issue 전환 사유가 적혀 있으면 정상 처리" 예외 명시

### 그 밖

- claim-rules 9절 자체 점검 11항 → **13항** (임상적 유의성·GRADE 항목 추가)
- 테스트 102건 → **106건** (verify +2, script +2)
- 전 스킬·에이전트 version 0.1.1

## 0.1.0 (2026-08-25) — 최초 릴리스

뉴스·근거 기반 유튜브 쇼츠 제작 플러그인 신설. `shopping-shorts` v0.7.1에서 검증된 제작 체인 계약(씬 시간표 소유권·인물 일관성·조립 지시서 필드 계약·검수 분기)을 이식하되, **사실 전달 콘텐츠에 필요한 검증 계층을 앞단에 새로 붙였다.** `shopping-shorts`와 독립적으로 동작한다.

초안 완성 후 **독립 에이전트 2인의 교차 감사**(체인 정합성 렌즈 / 콘텐츠 리스크 렌즈)를 거쳐 치명 7건·중 24건·경 12건을 릴리스 전 전건 반영했다. 아래 설계는 그 결과다.

### 신설 스킬 (7종)

| 스킬 | 성격 |
|---|---|
| `news-research` | 신규 — 수집일 고정, 4갈래 검색, 출처 원장(T1~T4·시의성), 1차 출처 되짚기, 정정·후속 확인, 이슈 후보 |
| `news-verify` | 신규 — 주장 분해, **5관문 검증**, 강도 판정(E1~E4·근거부재), 경고 카드(W-visit/W-urgent), 유효기한, 팩트 카드 + 탈락 목록 |
| `news-script` | `shorts-script` 구조 계승 + 뉴스형 3유형, **문장별 근거 카드 ID**, 필수 문구 예산, 기관명·수치 시간 가산 |
| `news-storyboard` | `shorts-storyboard` 8컬럼 → **10컬럼**(`role` + 출처 크레딧), 크레딧 강제 규칙, 데이터 카드 씬 설계, **자막 자체 점검** |
| `news-video-gen` | `shorts-video-gen` 계승 + 화면 글자 생성 금지, 생성 금지 소재, 만료·크레딧·role 게이트, `source_credit`·`verification_bundle` 필드 |
| `news-assemble` | `shorts-assemble` 계승 + **자막 2층**, 렌더 전 5게이트, 전환 겹침 보정, 크레딧 커버리지 검수 |
| `news-publish-kit` | `shorts-publish-kit` 계승 + 출처 목록(4요소), 면책, 발행 기한, **정정 점검 예약**, sponsorship 분기 |

### 신설 에이전트 (2종)

- `news-producer` — 7스킬 체인 총괄. **양보 가능/불가 목록을 분리**해 근거 강도·출처·경고 카드·만료는 사용자 요구로도 열리지 않는다. `tools` 미지정(MCP 생성 도구 누락 방지)
- `news-auditor` — 읽기 전용 검수 9영역. `tools`에 WebSearch·WebFetch 포함 — **제작 이후 정정 보도를 체인 밖에서 직접 재검색**하기 위함. 게시 후 7일·30일 점검에도 재사용

### 확립한 체인 계약

1. **검증 산출물 묶음** = 출처 원장 + 팩트 카드 세트(경고 카드 포함) + 탈락 목록 + 세트 값. verify가 만들고 **script 이후 모든 스킬이 통째로 나른다.** 중간 스킬이 일부만 넘기지 않는다 — publish-kit의 출처 목록·고정댓글과 auditor의 탈락 목록 대조가 종착지다
2. **사실의 단일 출처**: 대본 이후 모든 사실은 팩트 카드에서만 나온다
3. **강도가 어미를 결정한다**: E1~E4 사다리가 쓸 수 있는 표현을 고정한다. E1은 T1 필수, T2 단독은 E2 상한. 제목이 본문보다 셀 수 없다
4. **수치는 유형까지 검증한다** (관문 5): 상대값 단독 서술 금지(절대값 병기), 관찰연구 인과 서술 금지, 연구 대상 불일치 시 핵심 카드 승격 차단. **모든 게이트를 통과하던 오정보 경로를 닫은 것**
5. **크레딧 체인**: 씬 시간표 `근거 카드` → 스토리보드 출처 크레딧 컬럼 → 지시서 `source_credit` → 조립 크레딧 자막 레이어 → 발행 키트 출처 목록. 어느 지점이든 끊기면 다음 단계가 멈춘다
6. **만료 게이트**: `expiry_date`를 지나거나 **값이 없으면** storyboard·video-gen·assemble·publish-kit이 시작하지 않는다. 게시 후는 `content_expiry`와 7일·30일 정정 점검이 맡는다
7. **시간 계약**: script는 문장 단위 시간표만, storyboard가 씬 시간표를 확정(**배정 초가 유일한 계약값** — 예상 초는 조립으로 전달되지 않는다). **생성 전 실측은 storyboard가, 생성 후 실측은 assemble이** 처리한다. 길이 정합은 assemble 규칙 하나(±5% atempo 0.95~1.05 / 5~15% trim, duration 여유 없으면 사용자 선택 / 15% 초과 사용자 선택)
8. **`role` 소유권**: 스토리보드가 부여한다. 실촬영 경로는 video-gen을 거치지 않으므로 여기서 만들지 않으면 조립의 자막 스타일 분기가 성립하지 않는다
9. **인물 일관성**: 스틸 고정 → i2v 필수 체인, `person_group`별 앵커 관리, 앵커 승인 게이트. 단역(`Pn-x`)은 `person_anchor: null`이 정상
10. **멀티컷 씬**: 같은 `scene`에 `cut` + `cut_seconds`(합 = 배정 초), `scene4-1.mp4`, 나레이션은 cut 1에만(**씬 구간 전체에 재생된다 — cut 2의 null은 무음이 아니다**), 출처 크레딧은 씬 단위 통 유지
11. **전환 보정**: xfade는 총 길이를 줄이고 이후 씬 시작 시각을 앞당긴다. 겹침 총합만큼 자막·크레딧·나레이션 타이밍을 보정하고 총 길이 검증 기준에서 차감한다. 기본값은 하드컷
12. **지시서 자체 정합 검사**: `fact_cards` ↔ `source_credit` / `sequence` ↔ `clips[]`(브리지 씬 포함) / `cut_seconds` 합 = `assigned` / `trim_to` 길이 ≥ `cut_seconds` / `caution_scene`의 role. 하나라도 깨지면 지시서를 내지 않는다

### 안전·법규 설계

- **의료법 제56조 제1항의 수범자는 "의료인이 아닌 자"** — 일반 채널이 직접 대상이다(제89조①, 1년 이하 징역). 제56조②10호(기사·전문가 의견 형태 광고), 제27조②(의료인 유사 명칭), 제27조③(환자 소개·알선·유인)까지 표로 정리
- **식품표시광고법 제8조①1호의 수범자는 "누구든지"** — 판매·제휴 여부와 무관. 제26조 10년 이하 징역·1억원 이하 벌금
- **저작권법 제37조(출처 명시 의무)**를 출처 크레딧의 법적 근거로, **제7조 제5호(사실의 전달에 불과한 시사보도)**를 "사실만 가져와 새 문장으로 쓴다" 규칙의 근거로 명시
- 유튜브 정책 4종(의료 오정보 3범주 / 오해 유발 메타데이터 / 광고주 친화 / **반복적·대량 생산 콘텐츠**)을 규범 표에 포함
- **반박 대상 특정 금지** 절 신설 — 사실 적시도 명예훼손이 되므로 개인·채널·업체·병원을 지목하지 않는다. 시청자 사연 인용 규칙 포함
- **경고 카드도 T1/T2 출처 필수** — 가장 강하게 강제되는 항목이 가장 검증되지 않는 상태를 막는다. 근거 없으면 구체적 red flag 대신 비특이적 일반 권고로 폴백
- 검증 미실시 경로가 하류 게이트를 무력화하지 못하게 차단: `U` ID 부여 + "(미검증)" 크레딧 강제 + 임시 만료일 부여 + 첫 씬 고지 확인 게이트 + **발행 부적합 별도 판정**

### shopping-shorts와 의도적으로 다르게 한 것

- 제품 사진(A자료) 업로드 게이트 없음 — 캐스팅 시트·데이터 카드가 그 자리를 대신한다
- `sales_form` 대신 `sponsorship`(기본 `none`)
- 스토리보드 컬럼 8 → 10개 (`role` + 출처 크레딧)
- 조립 자막 1층 → 2층 (본문 + 크레딧)
- 검수 영역에 시의성·출처 추적성·근거 강도 정합·수치 해석 4영역 추가
- auditor 검수가 "제안"이 아니라 **표준 단계**

### 테스트

102건 (research 7 / verify 15 / script 14 / storyboard 18 / video-gen 15 / assemble 18 / publish-kit 15)

### 알려진 제약

- 표현 규칙(claim-rules.md)은 2026-08 기준 정리본이다. 법령 개정 시 갱신이 필요하다
- Consensus 등 학술 MCP가 없으면 학술 소스 수집이 웹 검색 품질에 의존한다
- 데이터 카드의 그래프 코드 생성은 조립 단계 수동 경로다 (자동 차트 생성은 후속 과제)
- 논문 철회 확인은 PubMed·Retraction Watch 접근이 가능한 환경을 전제한다. 불가하면 `정정 확인: 미실시`로 남고 해당 카드는 훅·핵심 카드로 쓸 수 없다
