# news-shorts

키워드 하나로 **오늘 기준 최신 뉴스·공공기관 발표·학술 논문**을 모아 검증하고, 그 근거 위에 유튜브 쇼츠를 만드는 플러그인입니다. 대본 → 스토리보드 → AI 영상 생성 → 자동 조립 → 발행 키트까지 이어져 **완성된 9:16 MP4**와 출처가 붙은 발행 자산을 돌려줍니다.

같은 마켓플레이스의 `shopping-shorts`가 **상품을 파는 쇼츠**를 만든다면, 이 플러그인은 **사실을 전하는 쇼츠**를 만듭니다. 두 플러그인은 독립적으로 동작하며 서로를 필요로 하지 않습니다.

## 무엇이 다른가

뉴스·정보 쇼츠는 예쁘게 만드는 것보다 **틀리지 않는 것**이 어렵습니다. 이 플러그인의 설계는 전부 그 한 지점을 향합니다.

| 위험 | 이 플러그인의 장치 |
|---|---|
| 가짜뉴스·미검증 주장 | 신뢰도 등급 T1~T4 · **1차 출처 필수** · 2차 전달 수치는 독립 2출처 · 정정/철회 확인 절차(PubMed·Retraction Watch 등 수행 경로 기록) |
| 의료·건강 과장 | 주장 강도 E1~E4 사다리로 **쓸 수 있는 어미까지 고정** · 절대 금지 표현 목록 · 경고 카드(`W-visit`/`W-urgent`) 필수, **경고 카드도 T1/T2 출처 필수** |
| **통계 오독** (가장 잡기 어려운 오정보) | **상대위험 단독 서술 금지** — 절대값 병기 필수 · 관찰연구 인과 서술 금지 · 연구 대상 집단 불일치 시 핵심 카드 승격 차단 |
| 며칠 뒤 낡은 내용 | 시의성 등급 A~D + **`expiry_date`(업로드 마감)** — 만료되거나 값이 없으면 스토리보드·생성·조립·발행이 전부 멈춤. **게시 후 7일·30일 정정 점검**과 `content_expiry`까지 |
| 출처 없는 영상 | 스토리보드에 **출처 크레딧 컬럼** 고정 → 조립이 자막 2층으로 번인 → 발행 키트가 출처 목록 산출. 어느 지점이든 끊기면 다음 단계가 멈춤 |
| AI가 그린 가짜 자료 화면 | 화면의 글자·수치·로고를 **AI에게 그리게 하지 않음** — 전부 자막 레이어로 이관 |
| 명예훼손 | **반박 대상 특정 금지** — 주장만 반박하고 개인·채널·업체·병원을 지목하지 않음 (사실 적시도 명예훼손이 됨) |
| 대량 생산 판정·수익화 상실 | 발행 체크리스트에 **"직전 5편과 구조·비주얼이 구분되는가"** — 같은 템플릿 반복은 유튜브 반복 콘텐츠 정책 대상 |

## 스킬 체인 (정본)

```
news-research ─→ news-verify ─→ news-script ─→ news-storyboard ─┬─→ news-video-gen ─→ news-assemble ─→ news-publish-kit
 (소스 수집·이슈)   (검증·팩트카드)   (대본·시간표)    (씬 설계·크레딧)  │    (AI 생성·검수)     (조립·자막 2층)    (발행 자산·출처 목록)
                                                              │                          ↑
                                                              └──── 실촬영 경로 ──────────┘
```

- **AI 생성 / 혼합** → video-gen을 거쳐 assemble로
- **실촬영** → video-gen을 건너뛰고 스토리보드에서 바로 assemble로
- 어느 경로든 종착지는 **assemble의 완성 MP4**이고, publish-kit이 마지막 단계입니다
- 발행 직전 **news-auditor 검수는 선택이 아니라 표준 단계**입니다 (FAIL이면 발행 자산을 확정하지 않습니다)

| 스킬 | 하는 일 | 트리거 예시 |
|------|---------|------------|
| `news-research` | 오늘 날짜 고정 → 4갈래 검색 → 출처 원장(T1~T4·시의성) → 1차 출처 되짚기 → 정정 확인 → 이슈 후보 5~7개 | "무릎건강으로 쇼츠 만들어줘", "요즘 뭐가 이슈야" |
| `news-verify` | 주장 분해 → **5관문 검증** → 강도 판정(E1~E4·근거부재) → 경고 카드 → 유효기한 → **팩트 카드 + 탈락 목록** | "이거 사실인지 확인해줘", "팩트체크" |
| `news-script` | `content_type` 확정 → 앵글 2안 → 유형별 5단계 → **문장별 근거 카드 ID** → 필수 문구 예산 → 나레이션 시간표. 기존 대본 100점 진단 모드 | "이 팩트로 대본 써줘", "내 쇼츠 뭐가 문제야" |
| `news-storyboard` | 고정 **10컬럼** 씬 표(`role`·출처 크레딧 포함) · 씬 시간표 확정 · 카드↔씬 매핑 · **자막 자체 점검** · AI 프롬프트 | "스토리보드 만들어줘", "씬 나눠줘" |
| `news-video-gen` | 씬 스틸 → image-to-video → 클립 검수 → 조립 지시서. 인물 일관성 · 데이터 카드 분기 · 생성 금지 소재 | "영상 생성해줘", "클립 뽑아줘" |
| `news-assemble` | 렌더 전 5게이트 → 트림·연결 → 전환 보정 → 오디오 믹스 → **자막 2층 번인** → 완성 MP4 | "조립해줘", "최종 영상 만들어줘" |
| `news-publish-kit` | 제목 3안 · 설명문 · **출처 목록** · 해시태그 · 고정댓글 · 체크리스트 · **정정 점검 예약** | "업로드 준비해줘", "출처 정리해줘" |

각 스킬은 단독으로도 쓸 수 있고, 순서대로 체이닝하면 풀세트가 나옵니다.

## 에이전트 (2종)

- **`news-producer`** — "무릎건강으로 쇼츠 처음부터 끝까지 만들어줘" 한 마디로 7스킬 체인 전체 주행. **양보 가능한 것(길이·앵글·경로)과 양보 불가한 것(근거 강도·출처·경고 카드·만료)을 명확히 구분**합니다
- **`news-auditor`** — 읽기 전용 검수 9영역: 시의성 · 출처 추적성 · 근거 강도 정합 · **수치 해석** · 안전/법규 · 정합성 · 영상 규격과 크레딧 커버리지 · 인물 일관성 · 발행 키트. **제작 이후에 나온 정정 보도를 직접 재검색**하며, 게시 후 7일·30일 점검에도 같은 검수를 돌립니다

## 체인이 나르는 값

스킬 간 계약입니다. 단계마다 다음 스킬로 반드시 넘어갑니다.

| 값 | 만드는 곳 | 쓰는 곳 |
|---|---|---|
| **검증 산출물 묶음** = 출처 원장 + 팩트 카드 세트(경고 카드 포함) + 탈락 목록 + 세트 값 | news-verify | **script 이후 모든 스킬이 통째로 나른다.** video-gen은 지시서 `verification_bundle`로, assemble은 리포트 체인 값으로. **publish-kit의 출처 목록·고정댓글과 auditor의 탈락 목록 대조가 종착지** |
| `content_type` (`issue`/`myth`/`guide`) | news-research 제안 → **news-script 확정** | 대본 구조 · 씬 규칙 · 검수 기준 |
| `expiry_date` / `content_expiry` | news-verify (만료 사유 우선) | **storyboard·video-gen·assemble·publish-kit의 시작 게이트** · 정정 점검 일정 |
| **씬 시간표** (씬 단위: 예상→배정→실측) | news-storyboard (script의 문장 단위 표를 받아 확정) | video-gen 클립 길이 · assemble 길이 정합·자막 타이밍. **배정 초가 유일한 계약값** |
| `role` (`hook`/`context`/`data_card`/`evidence`/`demo`/`caution`/`cta`) | news-storyboard | video-gen 모션 프리셋 · assemble 자막 스타일 · auditor 씬 비중 |
| `person_group` (`P1`, `P2` …) | news-storyboard | video-gen 앵커 스틸 관리 · auditor 프레임 대조 |
| `caution_scene` / `caution_level` | news-storyboard | assemble 렌더 게이트 · publish-kit 고정댓글 · auditor |

## 핵심 설계

- **사실은 팩트 카드에서만 나온다** — 대본 이후 단계는 카드에 없는 사실을 만들 수 없습니다. 카드마다 강도(E1~E4)가 붙고 **강도가 대본에서 쓸 수 있는 어미를 결정**합니다
- **수치는 유형까지 검증한다** — 상대위험 50% 감소가 2%→1%인지 40%→20%인지 확인하지 않으면 카드가 되지 않습니다. 이것이 "출처 있는 오정보"를 막는 유일한 지점입니다
- **출처가 화면에 남는다** — 저작권법 제37조의 출처 명시 의무이기도 합니다. 근거 카드가 있는 씬에 크레딧이 없으면 생성·조립이 멈춥니다
- **시의성이 두 개의 기한을 만든다** — `expiry_date`(업로드 마감)와 `content_expiry`(게시된 영상의 유효 종료). 게시 후 정정 절차까지 발행 키트가 안내합니다
- **AI는 그림만, 글자는 자막이** — AI가 그린 기관명은 **틀릴 수 있고 틀렸는지 우리가 확인할 방법이 없습니다.** 확인 불가능한 기관명이 화면에 뜨는 것 자체가 가짜 자료 화면입니다
- **인물 일관성** — 인물 등장 씬은 스틸 고정 → image-to-video 필수 체인. `person_group`별 앵커 관리로 identity switching을 막습니다
- **나레이션이 시간을 정한다** — 생성 전 실측은 스토리보드가, 생성 후 실측은 조립이 처리합니다. 배속(atempo) 보정은 0.95~1.05로 제한합니다
- **조립은 코드로** — ffmpeg 자동 렌더. 전환(xfade)을 쓰면 겹침만큼 자막·나레이션 타이밍을 보정합니다
- 타인 영상·기사 화면은 **분석에도 쓰지 않습니다**

## 우리가 받는 규제 (정확히)

흔한 오해가 "일반 채널은 의료광고 규제 대상이 아니다"인데, **의료법 제56조 제1항은 "의료인이 아닌 자"를 직접 금지 대상으로 삼습니다** (제89조 제1호 — 1년 이하 징역 또는 1천만원 이하 벌금). 특정 병원·의료인을 지목해 안내·연결하지 않는 것이 실무 방어선입니다.

식품·성분을 언급하며 질병 예방·치료 효능을 말하면 **식품표시광고법 제8조 제1항 제1호**가 적용되며, 수범자는 **"누구든지"**입니다 (제26조 — 10년 이하 징역 또는 1억원 이하 벌금). 판매·제휴 여부는 요건이 아닙니다.

전체 규범 표와 표현 규칙은 `news-verify/references/claim-rules.md`에 있습니다.

## 기본 프리셋

채널 「몸템연구소」(4050 건강라이프)를 1차 사용처로 설계했습니다. `news-script/references/news-type-briefs.md`의 **[건강·의료] 도메인 브리프**가 기본으로 적용되고, 생활·정책 / 경제·소비 / 과학·기술 브리프도 함께 들어 있어 다른 키워드로도 돌아갑니다.
