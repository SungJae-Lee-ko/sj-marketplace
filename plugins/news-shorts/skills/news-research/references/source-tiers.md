# 출처 신뢰도 등급 T1~T4 (2026 기준)

news-research가 원장을 만들 때, news-verify가 팩트 카드를 승격할 때 **공통으로 쓰는 유일한 등급 기준**이다. 다른 문서에서 등급을 가리킬 때는 반드시 `T1`~`T4` 고정 ID로 참조한다.

## 등급 정의

| ID | 이름 | 무엇인가 | 팩트 카드 근거로 |
|---|---|---|---|
| `T1` | 1차 공적·학술 원문 | 발표 주체가 직접 낸 원문 | **단독 사용 가능** |
| `T2` | 전문 2차 | 전문가 집단이 검토·정리한 2차 자료 | **단독 사용 가능** (T1 링크 병기 권장) |
| `T3` | 언론 보도 | 기자가 옮겨 쓴 것 | **단독 사용 불가** — T1/T2 1차 출처를 찾아야 승격 |
| `T4` | 비검증 | 개인·플랫폼 생성물 | **인용 금지** — 주제 발굴 단서로만 |

## T1 — 1차 공적·학술 원문

**국내 기관**

- 질병관리청 (KDCA) — 보도자료·주간건강과질병·국민건강영양조사
- 보건복지부 — 정책 발표·고시·통계
- 식품의약품안전처 (MFDS) — 허가·안전성 서한·건강기능식품 기능성 인정
- 국민건강보험공단 / 건강보험심사평가원 — 진료 통계·급여 기준
- 통계청 (KOSTAT) / KOSIS — 원 통계표
- 국립중앙의료원, 국립암센터 등 국립 기관 발표

**국제 기관**

- WHO, CDC, NIH, FDA, EMA, EFSA

**학술 원문**

- peer-reviewed 저널 게재 논문 원문 (DOI 확인 가능한 것)
- 체계적 문헌고찰·메타분석 (Cochrane Review 포함)
- 학회 공식 진료지침 (대한정형외과학회, 대한내과학회 등)

**주의**: 학술 원문이라도 **프리프린트(preprint)는 T1이 아니다.** 동료 심사를 거치지 않았으므로 `T2 이하`로 다루고 "심사 전 연구"임을 화면에 반드시 밝힌다.

## T2 — 전문 2차

- 대한의학회·전문 학회의 대국민 건강정보
- 대학병원·상급종합병원의 공식 건강정보 페이지 (서울대병원 의학정보 등)
- Cochrane 요약(Plain Language Summary), UpToDate 류 임상 요약
- 국가건강정보포털 등 기관이 운영하는 정리형 정보
- 국제 학술기관의 해설 자료 (Harvard Health, Mayo Clinic 등)

이들은 **1차를 잘 정리한 것**이므로 단독 인용이 가능하다. 다만 화면 크레딧에는 정리 주체를 적는다 (`출처: 대한정형외과학회`).

## T3 — 언론 보도

- 종합일간지·방송사·통신사 기사
- 의학·건강 전문지 기사
- 기관 보도자료를 옮겨 쓴 기사

**규칙**: T3는 **어디를 봐야 하는지 알려주는 지도**이지 근거 자체가 아니다.

- T3에서 발견한 주장은 반드시 원 발표(T1/T2)로 되짚는다 (news-research 3단계)
- 되짚기에 실패한 T3 주장은 팩트 카드로 승격하지 않는다
- 기사 문장을 대본에 옮겨 쓰지 않는다 — 사실만 가져오고 문장은 새로 쓴다 (저작권·문체 양쪽 이유)
- **기사 제목은 편집부가 붙인 것으로, 본문보다 세다.** 제목의 단정을 근거로 쓰지 않는다

## T4 — 비검증 (인용 금지)

- 개인 블로그·카페·커뮤니티 글
- 유튜브 영상·쇼츠의 주장
- SNS 게시물
- 광고성 기사(협찬·네이티브 광고)·업체 보도자료 그 자체
- AI가 만든 요약·검색 엔진의 자동 요약 (원문 확인 없이)
- 위키류

이들은 **"사람들이 무엇을 궁금해하는가"를 읽는 데만** 쓴다. 원장의 근거 행으로 올리지 않고, 화면·설명란에 출처로 적지 않는다.

## 등급이 애매할 때

| 상황 | 판정 |
|---|---|
| 기관 페이지인데 작성자·근거가 없다 | T2로 보되 팩트 카드에는 T1 하나를 더 붙인다 |
| 대학병원 이름이지만 실제로는 홍보성 콘텐츠 | T4 취급 (진료 유치 목적 글) |
| 전문가 인터뷰 기사 | 기사 자체는 T3, 그 전문가의 발언은 `E4 주장`으로만 (news-verify 표현 사다리) |
| 제약사·식품사 발표 | T4. 이해관계자 발표는 근거가 아니다. 단 규제기관 허가 사실은 T1(식약처)에서 확인 |
| 해외 기관 원문이 영어뿐 | T1 그대로. 번역은 우리가 하고, 크레딧은 원 기관명으로 |

## 유지보수 노트

기관명·URL 체계는 바뀐다. 원장 작성 중 링크가 죽어 있거나 기관이 개편된 흔적이 보이면 사용자에게 알리고 이 파일의 목록 갱신을 제안한다.
