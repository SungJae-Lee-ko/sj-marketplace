# 뉴스 쇼츠 리서치 (소스 수집·이슈 발굴)

**책임 한 줄**: 키워드 + 오늘 날짜 → 신뢰도·시의성이 매겨진 출처 원장 + 쇼츠 이슈 후보 5~7개 → 사용자가 고른 이슈 1개 확정.

이 스킬은 **모으는 자리이지 판정하는 자리가 아니다.** 여기서 "사실로 확인했다"고 말하지 않는다. 판정은 news-verify가 한다. **시의성·유효기한도 여기서는 참고값이며 확정은 news-verify가 한다** (검증 전 값은 탈락할 소스까지 포함하고 있어 필연적으로 달라진다).

## ID 규약 (이 플러그인 공통)

`S`=출처(원장) · `F`=팩트 카드 · `E`=주장 강도 · `T`=출처 등급 · `H`=훅 패턴 · `N`=나레이션 문장 · `P`=인물 그룹 · `U`=미검증 주장. **씬은 접두사 없는 정수**(씬 3), 컷은 `cut: 1`. 한 번 부여한 번호는 체인 끝까지 바뀌지 않는다.

## 0단계: 오늘 날짜를 먼저 고정한다 (필수)

`date` 명령 또는 환경의 현재 날짜로 **수집일(`collected_at`)을 먼저 확정**하고 산출물 머리에 적는다. 학습 시점 지식으로 "최근"을 판단하지 않는다 — 이 스킬의 존재 이유가 "생성하는 날짜 기준 최신"이다.

- 수집일이 확정되기 전에는 검색을 시작하지 않는다
- 모든 시의성 등급은 **수집일 대비 원문 발행일**로 계산한다 (기사가 재게시된 날짜가 아니라 원 발표일 기준)

## 1단계: 검색 계획 (키워드 확장)

사용자 키워드 하나("무릎건강")를 그대로 검색하지 않는다. 아래 4갈래로 벌려 각각 검색한다:

| 갈래 | 예 (키워드=무릎건강) | 노리는 것 |
|---|---|---|
| 기관·정책 | "질병관리청 무릎 관절", "건강보험 인공관절 급여", "보건복지부 근골격계" | T1 1차 발표·통계·제도 변화 |
| 연구·학술 | "무릎 골관절염 연구 2026", "knee osteoarthritis exercise trial" | T1 원논문 (Consensus MCP가 있으면 함께) |
| 보도 | "무릎 관절염 뉴스", "무릎 통증 기사" | T3 — **주제 발굴용이자 1차 출처로 되짚어 갈 실마리** |
| 통념·질문 | "무릎에서 소리 나면", "계단 무릎 통증 원인" | 시청자가 실제로 검색하는 말 (앵글 후보) |

- 검색은 국문·영문 양쪽으로 한다. 국내 보도가 해외 연구를 옮긴 경우가 많고, 그 원논문이 진짜 1차 출처다
- 연결된 MCP가 있으면 함께 쓴다: 학술은 Consensus, 공공 통계는 데이터 분석 계열 스킬·MCP. 없으면 웹 검색만으로 진행하고 그 사실을 산출물에 적는다

## 2단계: 출처 원장 작성 (이 스킬의 계약 산출물)

**references/source-tiers.md를 읽고** 각 소스에 등급을 매긴다. 원장은 아래 고정 컬럼으로 만든다 — 이 표가 news-verify와 news-publish-kit의 입력 데이터이므로 컬럼을 빼거나 이름을 바꾸지 않는다.

```
📚 출처 원장 (collected_at: 2026-08-25)
| ID | 등급 | 발행처 | 제목 | 원문 발행일 | 시의성 | 1차/2차 | URL |
|---|---|---|---|---|---|---|---|
| S1 | T1 | 질병관리청 | 국민건강통계 근골격계 항목 | 2026-08-19 | A | 1차 | https://... |
| S2 | T3 | ○○일보 | "무릎 연골 재생 연구 결과" | 2026-08-21 | A | 2차(S1 인용) | https://... |
| S4 | T2 | 대한정형외과학회 | 무릎 염발음 안내 | 2025-11-03 | D | 2차(지침 정리) | https://... |
```

컬럼 규칙:

- **ID** — `S1`부터 순번. 한 번 부여한 번호는 바꾸지 않는다 (팩트 카드가 이 ID로 출처를 가리킨다)
- **등급** — `T1`~`T4`. 판단 기준은 source-tiers.md 하나뿐이다
- **원문 발행일** — 기사에 적힌 날짜가 아니라 **최초 발표일**. 기사가 보도자료를 옮긴 것이면 보도자료 날짜를 쓰고 그 보도자료를 별도 행(1차)으로 추가한다
- **시의성** — 아래 표로 계산한다 (수집일 대비)

| 등급 | 원문 발행일 | 화법 허용 범위 (참고) |
|---|---|---|
| `A` | 7일 이내 | "이번 주", "며칠 전" 허용 |
| `B` | 30일 이내 | "최근", "이번 달" |
| `C` | 90일 이내 | 시점 표현 자제 ("올해" 정도) |
| `D` | 90일 초과 | **속보·시점 화법 전면 금지.** 상시 정보(가이드라인·해부학·오래된 정설)로만 사용 |

- **유효기한(`expiry_date`)은 여기서 계산하지 않는다.** news-verify가 카드 단위로, 만료 사유(정책 시행일·다음 통계 발표일 등)를 우선해 확정한다

- **1차/2차** — 2차면 무엇을 인용한 것인지 `2차(S1 인용)`처럼 적는다. **인용 대상을 찾지 못한 2차 소스는 그 사실을 적는다** (`2차(원출처 미확인)`) — news-verify가 이 표시를 보고 팩트 카드 승격을 막는다

## 3단계: 1차 출처 되짚기 (T3를 만났을 때 필수)

보도 기사(T3)에서 흥미로운 수치·주장을 발견하면 **거기서 멈추지 않는다.** 기사가 인용한 원 발표를 찾아 원장에 T1/T2 행으로 추가한다.

- "○○대 연구팀에 따르면" → 해당 논문·저널·기관 보도자료를 찾는다
- "정부에 따르면" → 해당 부처 보도자료·통계 원문을 찾는다
- **10분 이상 찾아도 원문이 없으면** 원장에 `2차(원출처 미확인)`으로 남기고 이슈 후보에서 **강등**한다 (삭제하지는 않는다 — 검증 단계가 판단할 근거로 남긴다)

## 4단계: 정정·후속 확인 (가짜뉴스 방어의 핵심)

이슈 후보로 올릴 소스는 **후속 보도를 한 번 더 검색한다**:

- 같은 주제로 이후에 나온 정정·반박·재현 실패 보도가 있는가
- 기관이 해명·정정 자료를 냈는가
- 학술 소스면 철회(retraction)·정오표가 있는가

발견하면 원장에 별도 행으로 추가하고 후보 옆에 `⚠️ 후속 있음`을 표시한다. **후속 확인을 하지 않은 소스를 이슈 후보로 올리지 않는다.**

## 5단계: 이슈 후보 산출 (5~7개)

원장을 재료로 쇼츠 한 편이 될 만한 후보를 뽑는다. 각 후보는 아래 형식으로 적는다:

```
### 후보 3 — "무릎에서 나는 소리, 대부분은 문제가 아니다"
- content_type 제안: myth (통념 검증) — **확정은 news-script**
- 근거 소스: S1(T1) · S4(T2) · 보강 S2(T3)
- 최고 시의성: B **(참고값 — 확정은 news-verify)**
- 4050 적합도: 상 — 계단·소리는 이 연령대 검색량이 큰 말
- 리스크: 소리 원인 중 일부는 실제 병증 → 병원 가야 하는 신호를 반드시 함께 넣어야 함
```

- **`content_type` 제안**은 3값 중 하나다. 이 값은 체인 전체가 나르므로 후보 단계부터 붙인다:

| content_type | 정의 | 어울리는 소재 |
|---|---|---|
| `issue` | 새로 나온 소식·발표를 해설 | 정책 변경, 신규 연구 결과, 통계 발표 |
| `myth` | 널리 퍼진 통념을 근거로 검증 | "○○하면 낫는다"류 속설, 잘못 알려진 상식 |
| `guide` | 근거 있는 실행법을 전달 | 가이드라인 기반 운동·생활 습관 |

- 후보마다 **T1 또는 T2 소스를 최소 1개** 갖춰야 한다. T3만으로 만들어진 후보는 목록에 올리되 `⚠️ 1차 출처 없음`을 붙이고 **추천하지 않는다**
- 후보는 서로 겹치지 않게 뽑는다 (같은 소스로 각도만 바꾼 후보 2개를 세지 않는다)
- 채널 프리셋이 있으면(기본: 4050 건강라이프) 적합도를 상/중/하로 적는다

## 6단계: 사용자 선택

후보 목록을 제시하고 **하나를 고르게 한다.** 무인 실행이면 `T1/T2 보유 + 시의성 최고 + 적합도 상` 순으로 1순위를 자동 선택하고 그 사실을 명시한다.

선택된 후보에 대해 다음 스킬(news-verify)로 넘길 값:

```
content_type: issue | myth | guide
collected_at: 2026-08-25
선택 이슈: (한 줄)
관련 출처: S1, S2, S4 …  (원장 전체를 함께 넘긴다 — 검증이 원장 밖 소스를 추가할 수 있다)
```

## 금지사항

- **T4 소스(블로그·커뮤니티·유튜브 요약·AI 생성 요약)를 원장의 근거 행으로 쓰지 않는다.** 주제 발굴 단서로만 보고, 원장에는 올리지 않는다
- 검색 결과의 요약 스니펫만 읽고 등급을 매기지 않는다 — 최소한 제목·발행처·날짜는 원문에서 확인한다. 확인하지 못했으면 원장에 `(미확인)`을 남긴다
- 수치를 원장에 옮겨 적지 않는다. 수치는 news-verify가 원문에서 직접 뜬다 (여기서 옮기면 전달 과정에서 틀어진다)
- 학습 지식으로 "요즘 ○○가 화제"라고 쓰지 않는다. 검색으로 확인한 것만 적는다
- 페이월·접근 불가 소스를 읽은 것처럼 요약하지 않는다 — `(본문 미접근)`으로 표시한다
