# 유튜브 쇼츠 규격 데이터 시트 (2026 기준, 최종 검증 2026-08)

스토리보드·영상 생성·조립·발행 키트가 공통으로 참조하는 수치. 여기 값과 산출물이 어긋나면 산출물이 틀린 것이다.

## 파일 규격

| 항목 | 값 | 비고 |
|---|---|---|
| 비율 | 9:16 세로 | 가로(16:9)는 3분 이하여도 일반 영상으로 분류됨 |
| 해상도 | 1080×1920 (권장) | 4K 세로 업로드 가능하나 시청 대부분 1080p |
| 최대 길이 | 3분 (180초) | 2024-10 확장. 오래된 가이드에 60초로 남아있음 주의 |
| 실무 권장 길이 | 60초 이하, 최적 25-40초 | 알고리즘은 완주율 가중. 뉴스형은 사실 3~5개가 한계 |
| 포맷/코덱 | MP4, H.264 | |
| 프레임레이트 | 24-60fps (30fps 표준) | |

## 자막 안전영역 (1080×1920 기준)

- **하단 약 300px**: 유튜브 UI(제목·채널·음악 정보)가 덮음 — 자막·핵심 정보 배치 금지
- **우측 약 120px**: 좋아요·댓글·공유 버튼 열 — 텍스트 침범 금지
- **상단 약 150px**: 기기별 크롭·상태바 영역 — 여유 확보
- 결론: **본문 자막은 세로 중앙~중하단(하단 300px 위), 좌측 정렬 우선**
- 피사체는 상단 2/3 안에 배치

## 출처 크레딧 레이어 (뉴스형 전용)

본문 자막과 **다른 층**이다. 두 층이 겹치면 둘 다 안 읽힌다.

| 항목 | 값 |
|---|---|
| 위치 | 하단 안전영역 바로 위 (y ≈ 1560~1600px), 좌측 정렬 |
| 크기 | 본문 자막의 **55~65%** |
| 스타일 | 흰 글자 + 검정 외곽선 2px, 또는 반투명 검정 바(60% 불투명도) 위 흰 글자 |
| 표시 시간 | 그 씬 구간 전체 (본문 자막이 여러 줄로 쪼개져도 크레딧은 통으로 유지) |
| 최대 길이 | 24자 이내 — 넘으면 발행처만 남기고 날짜를 뺀다 |

- 본문 자막이 2줄이면 크레딧과 겹치기 쉽다. 본문 자막의 하단 마진을 크레딧 높이만큼 올린다

## 발행 관련 실무 규칙

- 썸네일: 데스크톱 업로드는 커스텀 썸네일 불가. **모바일 유튜브 스튜디오 앱에서 프레임 지정 가능**
- 오디오: 쇼츠 오디오 라이브러리 곡은 3분 쇼츠에서도 **약 90초 제한(일부 곡 30·60초)**
- #Shorts 해시태그: 제목·설명에 포함하면 쇼츠 인식에 도움 (본 플러그인은 설명란에 배치)
- AI 생성 클립 포함 시: 업로드 화면 **"변경·합성된 콘텐츠" 공개 설정 체크**

## 알고리즘 특성 (기획 판단용)

- 쇼츠 피드는 일반 영상과 별도 알고리즘, 완주율이 핵심 신호
- 뉴스형은 정보 밀도가 높아 초반 이탈이 크다 — 훅에서 결론 방향을 흘려주는 편이 완주율에 유리하다
- 3분까지 허용돼도 완주율이 떨어지는 긴 쇼츠는 도달이 줄어드는 트레이드오프

## 유지보수 노트

플랫폼 규격은 변동된다. 산출 시점에 6개월 이상 지난 값이 의심되면(특히 길이·수익화·합성 콘텐츠 표기 정책) 웹 검색으로 재확인하고 이 파일 갱신을 사용자에게 알린다.
