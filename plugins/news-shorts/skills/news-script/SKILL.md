# 뉴스 쇼츠 대본

근거가 있는 이야기를 3초 안에 잡고 40~60초 안에 끝낸다. **재미를 위해 사실을 늘리지 않는 것**이 유일한 타협 불가 지점이다.

## 모드 판별 (가장 먼저)

| 모드 | 발동 조건 | 동작 |
|------|----------|------|
| 생성 (기본) | 새 대본 요청 | 아래 절차 |
| 진단 | 기존 대본·쇼츠를 주며 평가·개선 요청 | 맨 아래 [진단 모드] |

## 입력 (생성 모드)

1. **팩트 카드 세트** (F1, F2 … + 강도 + 출처 + 연구 설계·GRADE 확실성·대상·수치 유형·임상적 유의성 + 화면 표기 문구 + 허용/금지 화법 + 동반 필수 카드) — news-verify 산출물
2. **경고 카드** (`W-visit` 또는 `W-urgent`) — 건강 주제면 필수
3. **탈락 목록** — 여기 있는 주장은 대본에 쓰지 않는다. 자체 점검 항목이다
4. **출처 원장** — 대본이 직접 쓰지는 않지만 **검증 산출물 묶음의 일부로 그대로 다음 스킬에 넘긴다**
5. **`content_type`** (`issue` | `myth` | `guide`) — verify 산출물의 값은 research 제안값이다. **확정은 이 스킬이 한다.** 카드 내용과 맞지 않으면 확인받고 바꾸며, 바꿨으면 산출물 머리에 "확정: script"라고 적는다
6. **세트 값** — `freshness` · `expiry_date` · `content_expiry` · 핵심 카드 ID
7. 타깃 — 기본 프리셋은 40~50대. 지정되면 그 값 우선
8. 영상 길이 — 지정 없으면 아래로 추천하고 확인받는다

### 검증 없이 대본을 요구받았을 때

사용자가 링크·기사만 주고 바로 대본을 요구하면 news-verify를 먼저 돌리자고 제안한다. 거절하면:

- **건강 주제에서는 경고 카드 없이 진행하지 않는다.** 검증 전체를 거부해도 **경고 카드 1장만은 news-verify를 최소 실행**해 확보한다 (관문 1·4만 적용)
- 나머지 사실 문장에는 **미검증 주장 ID `U1`, `U2` …**를 부여하고, 화면 표기 문구 자리에 `출처: (미검증 — 설명란 링크)`를 강제로 채운다. 크레딧을 비우지 않는 것이 하류 게이트를 살려두는 유일한 방법이다
- 산출물 머리에 **`검증: 미실시`**를 명시하고, 강도를 전부 `E4`로 취급해 화법을 낮춘다
- `expiry_date`가 없으면 **`expiry_date: 수집일 + 7일`**을 임시로 부여한다 (비워두면 하류 만료 게이트가 통과해버린다)
- 이 경로의 산출물은 **발행 부적합**이다. 그 사실을 산출물과 사용자에게 함께 알린다

## 영상 길이

| 유형·목적 | 추천 길이 | 이유 |
|---|---|---|
| 단일 소식 전달 (`issue`) | 30-40초 | 사실 3개 + 해석 1개 |
| 통념 검증 (`myth`) | 40-55초 | 통념 → 반박 → 근거 → 대안 → 경고 |
| 근거 실행법 (`guide`) | 40-55초 | 방법 1개당 8-10초 + 근거·경고 |
| 복수 소식 묶음 | 50-60초 | 저장·공유 목적. 완주율은 떨어진다 |

**건강 주제는 필수 문구가 길이를 잡아먹는다.** 경고 카드·E3 병기·대상 집단·기관명·절대값 병기만으로 100음절 안팎이 나간다. 필수 문구를 빼서 길이를 맞추는 것은 이 플러그인에서 **가장 나쁜 실패**이므로, 넘치면 **길이를 먼저 올린다** (아래 [필수 문구 예산] 참조).

- AI 생성 씬이 포함돼도 **씬 길이를 5초 배수로 맞추지 않는다.** 생성은 모델 최소 단위로 하고 쓰는 구간만 트림한다

## 앵글 확정 (구조를 짜기 전에)

같은 팩트 카드로도 여러 편이 나온다. **서로 다른 앵글 2안을 제시하고 사용자가 고르게 한다.**

```
앵글 A — "소리가 문제가 아니라, 함께 오는 증상이 문제다" (myth / 핵심 카드 F1·F5)
앵글 B — "무릎 소리로 병원 가야 하는 3가지 신호" (guide / 핵심 카드 F5·F3)
```

- 앵글마다 **핵심 카드 ID**를 명시한다. 훅은 핵심 카드에서만 나온다
- 무인 실행이면 A를 택하고 그 사실을 명시한다

## 구조 (유형별 5단계)

**references/news-hook-patterns.md**를 읽고 훅 유형을 `H1`~`H10`으로 고른다. **references/news-type-briefs.md**의 유형 브리프 + 도메인 브리프를 적용한다.

아래 구간 시간은 **비율 가이드이며, 확정은 나레이션 시간표다.** 표의 초와 시간표가 어긋나면 시간표가 정본이다.

### `issue` — 이슈 해설 (35초 기준)

| 구간 | 비율 | 역할 |
|---|---|---|
| 훅 | ~8% | 무슨 일이 일어났는지 한 마디 |
| 사실 | ~26% | **무엇이 발표됐나 — 카드 1~2개.** 기관명·시점을 문장 안에 |
| 맥락 | ~26% | 그래서 이게 왜 새로운가 / 이전과 뭐가 다른가 |
| 내 얘기로 | ~24% | 시청자에게 무엇이 달라지는가 (해석은 해석이라고 밝힌다) |
| 마무리 | ~16% | 확인 행동 1개 ("설명란 출처 확인", "저장") |

### `myth` — 통념 검증

| 구간 | 비율 | 역할 |
|---|---|---|
| 훅 | ~7% | 통념을 그대로 소리 내어 말한다 |
| 통념 제시 | ~12% | 왜 다들 그렇게 아는지 (공감 — 비웃지 않는다) |
| 반박·근거 | ~40% | **카드 2~3개.** 강도에 맞는 어미로 |
| 그럼 뭐가 맞나 | ~24% | 대안·실제 기준. **경고 카드는 여기 또는 다음 구간에 반드시** |
| 마무리 | ~12% | 실행·확인 1개 |

- 반박 근거는 `E1`~`E2` 카드 또는 **`근거부재` 카드**를 쓴다. **E3로 통념을 뒤집지 않는다**
- 통념을 "틀렸다"고 하려면 E1~E2가 필요하지만, "**근거가 아직 확인되지 않았다**"고 하는 데는 근거부재 카드로 충분하다 — 후자가 myth의 기본 경로다
- **반박 근거가 E3로 내려앉으면**(GRADE low·very low, 또는 저자가 "결론을 내리기 어렵다"고 밝힌 경우) **myth를 포기하고 `issue`로 유형을 바꾼다.** 소재를 버리는 것이 아니라 "이런 연구가 나왔고 아직 결론은 안 났다"로 각도를 낮추는 것이다 (news-type-briefs 3부 라우팅). 유형을 바꿨으면 산출물 머리에 사유를 한 줄 적는다

### `guide` — 근거 실행법

| 구간 | 비율 | 역할 |
|---|---|---|
| 훅 | ~7% | 증상 호명 또는 결과 선공개 |
| 왜 필요한가 | ~15% | 근거 카드 1개로 짧게 |
| 방법 | ~45% | **방법 최대 3개.** 각각 [이름 → 횟수·시간 → 주의 1줄] |
| 근거·경고 | ~20% | 어느 기관·연구 권고인지 + **경고 카드 필수** |
| 마무리 | ~13% | 실행 유도 1개 |

**세 유형 공통 필수**
- **경고 카드 내용이 대본 안에 반드시 들어간다.** 나레이션으로만 지나가지 않고 자막으로도 뜬다 — 자막 지정은 storyboard가 하지만, **대본에 자막 문구를 명시해 넘긴다**. `W-urgent`면 나레이션에도 반드시 넣는다
- 강도 `E3` 카드 문장에는 **"아직 확정된 결론은 아닙니다"** 취지가 같은/다음 문장에 들어간다
- **상대값 수치를 말하면 절대값을 병기한다** (claim-rules 3-1) — 이것은 나레이션 필수다
- **`임상적 유의성: 미달(원문 명시)`인 카드의 수치는 그 사실과 같은 문장에 넣는다** (claim-rules 3-4). 수치만 떼어 자막에 띄우지 않는다 — 이것도 나레이션 필수다
- **관찰연구 기반 카드는 인과로 말하지 않는다** (claim-rules 3-2)
- 해석·의견은 사실과 분리해서 말한다 ("정리하면", "제 생각엔")

## 문장별 근거 추적 (계약 산출물 ①)

**대본의 모든 사실 문장에는 근거 카드 ID를 붙인다.**

- 사실 문장 → `(F2)` / 여러 카드 → `(F2·F3)` / 비사실 문장(훅 호명·연결어·해석) → `(—)`
- 검증 미실시 경로는 `(U1)`
- **카드 없는 사실 문장이 하나라도 있으면 그 문장을 지우거나 news-verify로 되돌린다.** 임의로 ID를 붙이지 않는다
- **동반 필수 카드**가 지정된 카드를 쓰면 그 짝도 대본에 넣는다 (예: F1을 쓰면 F5도)

## 시점 화법 규칙

- **문장별 시점 화법은 그 문장의 근거 카드 `freshness`가 허용하는 범위 안에서만 쓴다.** 세트 등급이 A라도 `D` 카드로 만든 문장에 "이번 주"를 쓰지 않는다
- 세트 `freshness`는 **훅과 제목에만** 적용된다
- 세트 `freshness: D`면 훅 패턴 `H9`(시점·신규형)를 쓰지 않는다

## 필수 문구 예산 (건강 주제 필수)

나레이션 시간표를 만들기 전에 **빼놓을 수 없는 문구의 음절 수를 먼저 집계한다.**

| 필수 문구 | 전달 수단 |
|---|---|
| 경고 카드 (`W-visit`) | 자막 + 나레이션 |
| 경고 카드 (`W-urgent`) | **자막 + 나레이션 (전체 정지 화면)** |
| 상대값의 절대값 병기 | **나레이션 필수** |
| E3 병기 "아직 확정된 결론은 아닙니다" | 나레이션 |
| 대상 집단 명시 ("65세 이상에서") | **자막 전용 가능** |
| 기관명 + 발행일 | **자막 전용 가능** |
| E4 발화자·소속 | 나레이션 (짧게) + 자막 |

- **자막 전용으로 이관한 문구는 나레이션 시간표에서 제외한다.** 읽고 지나가도 되는 것(대상 집단·발행일)과 무음 시청자가 놓치면 안 되는 것(경고·절대값)을 구분하는 것이 이 표의 목적이다
- 필수 문구 음절 합계를 시간표에 **별도 행으로 집계**한다. 목표 길이의 40%를 넘으면 **길이를 5~10초 올릴지 사용자에게 묻는다** — 필수 문구를 깎지 않는다

## 나레이션 시간표 확정 (계약 산출물 ② — 문장 단위)

**시간의 기준은 나레이션 길이다.**

**책임 경계**: 이 스킬은 **문장 단위 예상 시간표**까지만 만든다. 씬은 아직 없다. **씬 단위 시간표는 news-storyboard가 이 표를 받아 확정한다.**

1. 구간별 나레이션 문장을 확정하고 **문장마다 일련번호(N1, N2 …)를 붙인다**
2. 음절 수로 예상 길이를 계산한다 — 한국어 쇼츠 나레이션은 초당 약 4.5음절
   ```
   예상 초 = 음절수 ÷ 4.5 + 0.4    (0.4초는 문장 앞뒤 호흡)
   ```
   - **기관명 1개당 +0.2초, 소수점 있는 수치 1개당 +0.3초**를 더한다 (실제로 더 느리게 읽힌다)
3. 총합 + 무나레이션 여유가 목표 길이 이내여야 한다. 넘치면 [필수 문구 예산]을 먼저 확인하고, 필수 문구가 아닌 문장부터 줄인다
4. 표에 [문장 ID → 구간 → 근거 카드 → 음절수 → 예상 초]를 남기고, **필수 문구 합계 행**을 함께 싣는다
5. 이 값은 **예상치**다. 실측과 어긋났을 때:
   - **영상 생성 전** TTS 실측 → **news-storyboard [씬 시간표 확정]**이 배정 초를 고친다
   - **영상 생성 후** 실측 → **news-assemble [길이 정합 규칙]**이 처리한다
   - 이 두 규칙 외에 별도 허용 오차를 여기서 정하지 않는다

**권장 — 나레이션 선(先) 생성**: 클립 생성에 크레딧을 쓰기 전에 TTS를 먼저 만들면 되돌림이 사라진다.

**나레이션 문장 길이**: 한 문장 **25음절 이내**, 호흡 단위는 **12~15음절**로 끊는다.

## 출력 형식

```
🎬 [주제] 뉴스 쇼츠 대본 (총 XX초)
content_type: myth  (확정: script)
검증: 실시 / collected_at: 2026-08-25 / 세트 freshness: B
expiry_date: 2026-10-24 (업로드 마감) / content_expiry: 2027-01-22
훅 패턴: H1 (통념 인용형) / 핵심 카드: F1

[0:00-0:03] 훅
  나레이션(N1): "..." (—)
  자막: "「무릎에서 소리 나면 연골 닳은 거다」"     ← 통념은 따옴표

[0:03-0:12] 통념 제시 → 반박
  나레이션(N2): "..." (F1)
  자막: "..."
  출처 표기: "출처: 대한정형외과학회(2025.11)"     ← 카드의 화면 표기 문구
  자막 전용: "대상: 일반 성인"                    ← 나레이션 시간표에서 제외
```

## 금지사항

- "안녕하세요 여러분" 류 인사로 시작 금지
- **카드에 없는 사실을 쓰지 않는다.** "아마 ~일 것", "보통 ~라고 한다" 같은 출처 없는 일반화 금지
- **탈락 목록의 주장을 쓰지 않는다**
- claim-rules.md 1절 절대 금지 표현 사용 금지
- 기사 문장 복붙 금지 — 사실만 가져오고 문장은 새로 쓴다
- 공포 마케팅 금지 ("모르면 큰일 납니다")
- 낚시 훅 금지 — **훅에서 던진 질문은 영상 안에서 반드시 답한다**
- 특정 개인·업체·병원을 지목한 반박 금지 (claim-rules 7절)
- 이모지는 출력 구분용 외 나레이션·자막에 남용 금지

## [진단 모드] 기존 대본 채점

**이 채점은 형식 채점이다 — 대본에 적힌 사실이 맞는지는 검증하지 않는다.** 이 문장을 출력에 반드시 포함한다.

**채점표 (100점)**

| 항목 | 배점 | 기준 |
|---|---|---|
| 훅 (0-3초) | 20 | 인사말 시작 -10 / H1~H10 해당 +10 / 첫 문장이 사실·통념·호명 중 하나 +10 |
| **근거 추적** | 25 | 사실 문장에 카드 ID가 붙어 있는가. 근거 없는 사실 문장 1개당 -8 |
| **출처 표기** | 20 | 기관·발행일이 자막으로 뜨는가 15 / 나레이션에만 8 / 없음 0. 수치를 말하는데 크레딧 없으면 -5 |
| 구조 | 15 | 유형별 5단계 충족, 빠진 단계당 -4 |
| 경고·안전 | 10 | 경고 카드 내용이 자막으로 있는가 10 / 나레이션만 5 / 없음 0 |
| 시의성 | 10 | 시점 화법이 근거 범위 안인가 / 만료 소재가 아닌가 |
| 표현 규칙 (감점 전용) | -40까지 | claim-rules 1절 금지 표현 건당 -10, E3·E4 일반화 건당 -8, **상대값 단독 서술 건당 -10**, 관찰연구 인과 서술 건당 -8 |

**출력**: ① 형식 채점 고지 ② 판별한 `content_type` + 총점 + 항목별 표 ③ **최우선 수정 1개** + 구체 교체안 ④ 2-3순위 ⑤ 성과 지표를 받았으면 연결 해석 ⑥ **"수정 반영본을 만들려면 이 대본의 주장을 먼저 news-verify로 검증해야 합니다. 검증부터 시작할까요?"**

- 점수는 근거 없이 주지 않는다 — 해당 대목을 인용해 이유를 붙인다
- **진단 대상 대본의 미검증 사실을 그대로 살려 재작성하지 않는다.** 재작성은 검증을 거친 뒤에만
- 진단만 요청받았으면 재작성을 임의로 하지 않는다
