# 뉴스 쇼츠 자동 조립 (Auto Assembly & Render)

**책임 한 줄**: 씬 클립 + 나레이션 + 확정 스토리보드 → 트림·연결·**자막 2층**·오디오·전환을 코드로 합성 → 완성된 9:16 MP4.

뉴스형의 추가 책임: **출처 크레딧이 실제로 화면에 남게 하는 것.** 크레딧이 빠진 완성본은 이 플러그인에서 완성본이 아니다.

## 렌더 전 게이트 (순서대로, 하나라도 걸리면 멈춘다)

1. **만료 확인** — 오늘 날짜가 `expiry_date`를 지났으면 렌더하지 않는다. news-verify 재실행 제안. **`expiry_date`가 아예 없어도 렌더하지 않는다** (없음은 무기한이 아니다). 검증 미실시 산출물이면 `검증: 미실시` 표시가 대본에 있으므로 아래 게이트 5도 함께 적용한다
2. **크레딧 정합** — 사실 문장이 있는 씬에 크레딧이 없으면 렌더하지 않는다
   - AI 경로: `scene_timing[].fact_cards`가 비어 있지 않은 씬에 `source_credit`이 없는 경우
   - 실촬영 경로: 씬 시간표의 `근거 카드`가 채워진 씬에 스토리보드 출처 크레딧 컬럼이 `—`인 경우
   → **news-storyboard로 되돌린다**
3. **경고 카드 확인 — 결손 유형에 따라 되돌림 대상이 다르다**

   | 결손 | 되돌림 대상 |
   |---|---|
   | 팩트 카드 세트에 경고 카드 자체가 없다 | **news-verify** |
   | 카드는 있는데 스토리보드 어느 씬 자막에도 없다 (`caution_scene` 없음) | **news-storyboard** |
   | 스토리보드에는 있는데 자막 파일에 누락됐다 | **여기서 자막 파일만 고쳐 재렌더** |

   `caution_level`이 `W-urgent`면 **자막 + 나레이션 둘 다** 있어야 한다. 나레이션이 없으면 news-script로 되돌린다
4. **`review` 게이트**
   - AI 경로: `pass`가 아닌 클립은 조립에 넣지 않는다
   - **실촬영 경로에는 `review`가 없다.** 대신 아래 [실촬영 검수 4항]을 사용자에게 제시하고 확인받는다. 확인 없이 렌더하지 않는다
5. **검증 미실시 확인** — 대본 머리에 `검증: 미실시`가 있으면, **첫 씬 자막에 "검증되지 않은 정보" 고지**가 있는지 확인한다. 없으면 렌더하지 않고 스토리보드로 되돌린다

이 게이트들은 **비용이 이미 든 뒤의 마지막 방어선**이다. 조용히 통과시키지 않는다.

### 실촬영 검수 4항 (실촬영 경로 필수)

클립을 받은 뒤 프레임을 뽑아 사용자와 함께 확인한다:

1. 배경에 **병원·약국 간판, 브랜드 제품, 로고**가 찍히지 않았는가
2. 배경에 **제3자 얼굴**이 들어가지 않았는가 (초상권)
3. 출연자 **본인 동의**를 확보했는가
4. 촬영 장소가 **의료기관 내부가 아닌가** (의료법 제56조 리스크)

## 입력 확보

### 1. 클립 수집

1. **연결된 로컬 폴더 자동 스캔이 1순위** — 프로젝트 폴더(또는 `clips/`)에서 영상 파일을 찾아 씬 번호와 매칭한다. 파일명에 씬 번호가 있으면 자동 매칭(`scene2*.mp4`, `씬2*.mp4`), 없으면 생성 시각·길이로 추정하고 매칭표를 사용자에게 확인받는다
   - **한 씬이 여러 컷인 경우**: 같은 `scene`이 `cut` 1·2·3으로 들어온다. 파일명은 `scene4-1.mp4` 규칙으로 매칭하고, **연결 순서는 씬 오름차순 → 같은 씬 안에서는 `cut` 오름차순**이다
2. 클립이 원격 URL로만 있으면 **직접 다운로드를 먼저 시도한다.** 차단으로 실패하면 재시도하지 말고 "클립을 연결 폴더에 넣어달라"고 파일 단위로 안내하고, 허용 목록에 CDN 도메인 추가를 1회 안내한다
   - **샷 단위 연속 생성 클립**(조립 지시서 `clips[].shot`이 채워진 경우): 같은 샷의 씬들은 **같은 url을 공유**한다 — url당 1회만 다운로드하고(폴더 반입 파일명은 `shot1*.mp4`도 허용, `shot` 필드로 매칭) 씬별 `trim_to` 구간으로 분할한다. **같은 shot의 인접 씬 경계에는 전환 효과(xfade)를 적용하지 않는다** — 프레임이 연속인 이어지는 영상이다. `assembly.transitions`가 그 경계를 가리키면 news-video-gen으로 되돌린다
3. **실촬영 클립도 같은 폴더에서 받는다** — 조립 지시서가 없으므로 **스토리보드 씬 표(10컬럼) + 씬 시간표 + 표 아래 체인 값 줄**을 직접 입력으로 쓴다
   - `trim_to`가 없다. **씬 시간표의 배정 초만큼**을 각 클립에서 잘라 쓰되 어느 구간을 쓸지 확인받는다 (기본 제안: 앞 0.3초를 버리고 배정 초만큼)
   - 출처 크레딧·`role`은 **스토리보드 컬럼에서 직접 읽는다**
4. **지시서 정합 검사** (AI 경로) — 아래가 깨지면 news-video-gen으로 되돌린다:
   - 씬별 `cut_seconds` 합 ≠ 그 씬의 `assigned`
   - 어느 클립의 `trim_to` 길이 < `cut_seconds` (빈 구간이 생긴다)
   - `assembly.sequence`에 있는데 `clips[]`에 없는 씬 (브리지 씬 누락)
5. **제외 처리** — `review`가 `pass`가 아닌 클립을 뺐으면:
   - 씬 시간표에서 그 행을 빼고 총 길이를 다시 합산한다. **갱신된 표가 이후의 정본**이며, 씬 구간 누적·나레이션 배치·총 길이 검증이 모두 갱신본 기준이다
   - **제외한 씬이 팩트 카드를 소비하던 씬이면** 그 사실이 영상에서 사라진다. 임의로 진행하지 말고 아래 셋 중 선택을 받는다:
     - ① 그 씬만 재생성
     - ② **인접 씬으로 문장·크레딧을 옮긴다** — 단 **인접 씬 클립의 `duration`에 여유가 있어 5% 이내 연장으로 흡수 가능할 때만.** 그 외에는 이 선택지를 제시하지 않는다
     - ③ 그대로 제외
   - 제외 사실·씬 번호·갱신 총 길이를 리포트에 적는다
6. 일부 씬이 미확보면 확보된 씬만으로 가조립본을 만들지, 기다릴지 묻는다

### 2. 나레이션 수집 (클립과 동등한 필수 입력)

1. **연결 폴더에서 나레이션 오디오를 스캔한다** — `narr*.mp3`, `나레이션*.mp3`, `scene*_narr.*`, `.wav`/`.m4a` 포함. 파일명에 씬 번호가 있으면 자동 매칭, 없으면 생성 시각 순 + 스토리보드 나레이션 컬럼 순서로 대응시키고 **매칭표를 확인받는다**
2. 조립 지시서가 있으면 `clips[].narration_file`을 우선 신뢰한다
3. **나레이션 파일이 없고 나레이션 컬럼이 채워져 있으면**: TTS 생성을 제안한다. **크레딧 소모를 사전 고지하고 승인받는다**
   - 뉴스형 나레이션은 **기관명·수치를 또박또박 읽는 톤**이 필요하다. 과한 감정 연출 보이스는 신뢰도를 떨어뜨린다
4. 나레이션 없는 기획이면 그대로 진행하고 리포트에 "나레이션 없음(의도된 구성)"으로 명시한다
5. 나레이션 컬럼이 통째로 비어 있으면 스토리보드가 불완전한 것이다 — 임의로 채우지 말고 되돌린다

### 3. 타이밍 정보 — 씬 시간표가 유일한 기준

| 무엇 | 어디서 |
|---|---|
| 씬 구간(시작·끝) | 씬 시간표의 **배정 초** 누적 (실측 초가 채워져 있으면 그 값 우선). **예상 초는 쓰지 않는다** |
| 클립 사용 구간 | `trim_to` / 실촬영은 [클립 수집] 3항 |
| 멀티컷 씬의 컷 길이 | `cut_seconds` (합 = 그 씬의 배정 초) |
| 본문 자막 타이밍 | **씬 구간 그대로.** 한 씬에 자막이 ` / `로 2줄 이상이면 씬 구간을 줄 수만큼 균등 분할 |
| **출처 크레딧 타이밍** | **씬 구간 통으로.** 본문 자막이 쪼개져도 크레딧은 나누지 않는다 |
| 나레이션 배치 | 씬 시작 시각 (adelay). **전환 겹침을 보정한 시각이다 — 아래 [전환 보정]** |
| 전환 | `assembly.transitions` / 실촬영은 스토리보드 전환 가이드 |
| 오디오 큐 | 스토리보드 오디오 컬럼 |

- 씬 시간표가 아예 없으면 스토리보드로 되돌린다

## 길이 정합 규칙 (나레이션 우선)

**생성 전** TTS 실측은 news-storyboard가 배정 초를 고쳐 처리한다. **생성 후** 실측이 어긋나면 여기서 처리한다 — 클립이 이미 과금됐으므로 조립이 흡수한다.

| 차이 | 처리 |
|---|---|
| ±5% 이내 | `atempo`로 미세 보정 (**0.95~1.05**) |
| 5~15% | **클립 쪽을 먼저 조정한다** — `trim_to` 구간을 늘리거나 줄여 씬 길이를 나레이션에 맞춘다. **단 `duration`에 여유가 없으면(늘릴 수 없으면) 15% 초과와 같이 사용자 선택으로 넘어간다.** 조정했으면 총 길이 변화를 고지하고 **씬 시간표를 갱신한다** |
| 15% 초과 | **자동 처리하지 않는다.** ① 나레이션 문장 축약(news-script 회귀) ② 해당 씬 클립 연장 재생성 중 선택을 받는다 |

- `atempo` 허용 범위는 **0.95~1.05 하나뿐이다**
- 조정을 했으면 **갱신된 씬 시간표가 이후의 정본이다.** 리포트에 갱신 표를 싣고 publish-kit·auditor에 넘긴다
- 조립은 씬 시간을 **검증하는 자리이지 재설계하는 자리가 아니다.** 위 표에 없는 조정을 하지 않는다

## 전환 보정 (xfade를 쓸 때 — 필수)

xfade는 경계마다 겹치므로 **총 길이가 줄고 이후 씬의 시작 시각이 전부 앞당겨진다.** 보정하지 않으면 자막·크레딧·나레이션이 통째로 밀린다.

1. `assembly.transitions`에서 **전환 겹침 총합 Σ(sec)**을 먼저 계산한다
2. **각 씬의 시작 시각을 그 씬 앞에 놓인 전환들의 겹침 합만큼 앞당긴다.** 자막·크레딧·나레이션(adelay) 타이밍을 모두 이 보정된 시각으로 계산한다
3. 총 길이 검증 기준을 **`최종 씬 시간표 총합 − 전환 겹침 총합 ±0.5초`**로 한다
4. **기본값은 하드컷이다.** `transitions`가 비어 있으면 보정도 없다 — 전환은 필요한 경계에만 쓴다

## 조립 파이프라인 (ffmpeg 기본 경로)

```
[1] 정규화: 모든 클립을 1080×1920 / 30fps / H.264 / 48kHz로 통일
    ffmpeg -i in.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30" \
      -c:v libx264 -preset medium -crf 18 -c:a aac -ar 48000 norm_sceneN.mp4
    - 정지 스틸로 대체한 data_card·caution 씬은 켄번스로 클립화:
      ffmpeg -loop 1 -i still.png -t {씬 초} -vf "zoompan=z='min(zoom+0.0006,1.08)':d={초×30}:s=1080x1920,fps=30" ...
      (caution 씬은 zoompan 없이 완전 정지로 둔다)
[2] 트림: 씬별 trim_to 구간만 추출 (-ss/-t, 재인코딩으로 프레임 정확도 확보)
[3] 연결: concat demuxer로 씬 순서대로. transitions에 지정된 경계만 xfade(0.2-0.3초)
    → 적용했으면 위 [전환 보정]을 반드시 수행
[4] 오디오 믹스 (3층 순서를 지킨다)
    ① 나레이션: 씬별 파일을 해당 씬 시작 시각(전환 보정 반영)에 배치 (adelay)
       - 트랙을 -16 LUFS 기준으로 정규화(loudnorm), 피크 -3dBTP 이하
       - ffprobe로 실측 길이를 먼저 확인하고 위 길이 정합 규칙 적용
       - 씬 경계에서 잘리지 않게 앞뒤 0.1초 패딩 확인
    ② 클립 자체 오디오: 오디오 컬럼 기준으로 유지/음소거. 유지 구간도 나레이션과 겹치면 -8dB 덕킹
    ③ BGM: 받았으면 -18dB 내외, 나레이션 구간은 사이드체인 또는 -6dB 추가 덕킹
       BGM이 없으면 나레이션+클립 오디오만으로 완성하고 "발행 전 유튜브 오디오 라이브러리에서 추가 가능" 안내
    → 최종 믹스 -14 LUFS 내외, 피크 -1dBTP 이하
[5] 자막 — **2층으로 만든다 (뉴스형 핵심)**
    ASS 파일 하나에 스타일 2개를 정의하고 함께 번인한다: ffmpeg -vf "ass=subs.ass"

    ▸ Style: Main (본문 자막)
      - 텍스트: 스토리보드 **자막 컬럼** (나레이션 컬럼이 아니다)
      - 타이밍: 씬 구간 (` / `로 2줄 이상이면 균등 분할)
      - 위치: 세로 중앙~중하단. 하단 300px·우측 120px·상단 150px 침범 금지
      - 스타일: 굵은 고딕(Noto Sans KR 계열), 흰 글자 + 검정 외곽선 3px, 키워드만 옐로 강조
      - `role: data_card` → 폰트 1.15배, 화면 중앙
      - `role: caution` → 폰트 1.15배, 화면 중앙. **`caution_level: W-urgent`면 1.4배 + 화면 전체 정지 + 배경 딤(50%)**

    ▸ Style: Credit (출처 크레딧)
      - 텍스트: `source_credit` (실촬영은 스토리보드 출처 크레딧 컬럼)
      - 타이밍: **씬 구간 통으로**
      - 위치: 하단 안전영역 바로 위 (y ≈ 1560~1600), 좌측 정렬
      - 크기: 본문의 55~65%. 흰 글자 + 검정 외곽선 2px 또는 반투명 검정 바 위 흰 글자
      - **본문 자막의 하단 마진을 크레딧 높이만큼 올려 겹치지 않게 한다**

    - 폰트 미존재 채로 렌더 금지 — 한글 깨짐(□□) 검수 실패의 최다 원인. 없으면 설치한다
    - (guide) 횟수·시간 카운트 자막이 스토리보드에 있으면 반드시 포함
    - 경고 카드 자막은 어떤 경우에도 빠뜨리지 않는다
[6] 최종 렌더: 1080×1920, H.264, 30fps, yuv420p, AAC.
    총 길이가 **(최종 씬 시간표 총합 − 전환 겹침 총합) ±0.5초**인지 확인
```

- 모든 중간 산출물은 작업 폴더에, 최종본만 전달한다

## Remotion 경로 (선택 — 모션 그래픽 자막)

정적 ASS 자막으로 부족한 경우(단어 단위 팝업, 수치 카운트업, 그래프 애니메이션)에만 제안한다. 렌더 시간이 ffmpeg 대비 수 배 길고 의존성 설치가 필요하므로 기본값이 아니다.

## 검수 (렌더 후 필수)

1. 프레임을 3-4장 추출해 확인: 본문 자막 안전영역 준수 / **출처 크레딧이 실제로 보이는가** / 두 층이 겹치지 않는가 / 한글 깨짐 없음 / 씬 순서 정확
2. **크레딧 커버리지 확인** — `fact_cards`가 있는 **모든** 씬 구간에서 프레임을 하나씩 뽑아 크레딧을 확인한다. 하나라도 비면 자막 파일을 고쳐 다시 렌더한다
3. **경고 카드 프레임 확인** — `caution_scene` 구간에서 프레임을 뽑아 문구가 실제로 보이는지 확인한다
4. 총 길이·해상도·fps를 ffprobe로 확인해 **최종 씬 시간표(전환 보정 반영)**와 대조한다
5. **오디오 확인**: 나레이션이 해당 씬에 실제로 들어갔는지 파형·구간으로 확인. `W-urgent` 씬은 나레이션 유무를 별도로 확인
6. 이상 없으면 최종본을 사용자에게 전달하고 연결 폴더에 저장한다 (파일명: `{주제}_news_shorts_final.mp4`)

## 출력

- 완성 MP4 1개 (+ 요청 시 자막 없는 클린본)
- **조립 리포트** — 아래 항목을 모두 기재한다:
  1. 사용한 씬·트림 구간 / 조립에서 제외한 클립과 사유
  2. 나레이션 매칭 결과와 길이 보정 내역(`atempo` 배율·`trim_to` 조정)
  3. **최종 씬 시간표** (조정본)
  4. **출처 크레딧 배치표** — 씬별 [근거 카드 → 크레딧 문구 → 표시 구간]
  5. **전환 목록과 겹침 총합** (총 길이 검증 기준값)
  6. 자막·BGM 처리 (guide면 카운트 자막, 건강 주제면 경고 카드 자막·등급 포함 여부)
  7. 총 길이·해상도·fps·LUFS
  8. **체인 값**: `content_type` · `freshness` · `expiry_date` · `content_expiry` · `storyboard_ref` · `caution_scene`/`caution_level` · **`verification_bundle`**(출처 원장·팩트 카드·탈락 목록의 경로 또는 내용)
  9. 지시서에 `note`가 있으면 그 내용
- ⚠️ AI 생성 클립이 포함된 영상임을 리포트에 명시 — 유튜브 "변경·합성된 콘텐츠" 공개 설정 (publish-kit에 전달)

## 이 스킬을 사용하지 말아야 할 때

- 클립이 하나도 없음 → news-video-gen(생성) 또는 실촬영 먼저

- 뉴스 화면·타인 영상을 소재로 넣어달라는 요청 → 거절하고 분석 전용 원칙을 안내한다
