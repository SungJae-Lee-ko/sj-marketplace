# 뉴스 쇼츠 검증 (팩트 카드 확정)

**책임 한 줄**: 출처 원장 + 선택된 이슈 → 주장 단위로 쪼개 5관문 통과 → **영상에 쓸 수 있는 팩트 카드 세트 + 쓰면 안 되는 주장 목록**.

이 스킬의 기본 자세는 **회의**다. 통과시키려고 검사하지 않고 **떨어뜨릴 이유를 찾으려고** 검사한다. 근거가 부족하면 "부족하다"가 정답이며, 억지로 승격하지 않는다.

## ID 규약 (이 플러그인 공통)

`S`=출처(원장) · `F`=팩트 카드 · `E`=주장 강도 · `T`=출처 등급 · `H`=훅 패턴 · `N`=나레이션 문장 · `P`=인물 그룹 · `U`=미검증 주장. **씬은 접두사 없는 정수**(씬 3), 컷은 `cut: 1`.

## 입력

- news-research의 **출처 원장** (S1, S2 …) + `collected_at` + `content_type` 제안 + 선택된 이슈
- 원장 없이 호출됐으면(사용자가 기사 링크만 던진 경우): 그 자리에서 최소 원장을 만든다 — 링크의 등급·발행처·원문 발행일·1차/2차를 확인해 `S1`부터 채운다. **원장 없이 검증하지 않는다**
- research가 계산한 시의성·유효기한은 **참고값**이다. 확정은 이 스킬이 한다 (4단계)

## 1단계: 주장 분해

이슈를 **검증 가능한 최소 단위 주장**으로 쪼갠다. "무릎 건강에 좋다"는 검증 단위가 아니다.

| 나쁜 단위 | 좋은 단위 |
|---|---|
| "걷기가 무릎에 좋다" | "중강도 걷기는 무릎 골관절염 환자의 통증 점수를 낮춘다" |
| "인공관절 수술이 늘었다" | "2025년 국내 슬관절 전치환술 건수는 전년 대비 N% 증가했다" |

- 주장은 5~8개면 충분하다. 30~45초 쇼츠에 들어가는 사실은 결국 3~5개다
- **수치·연도·기관명이 들어간 주장을 우선 분해한다** — 화면에 뜨는 순간 틀리면 바로 티가 난다

## 2단계: 주장별 검증 (5관문)

각 주장은 아래 다섯을 **모두** 통과해야 팩트 카드가 된다.

### 관문 1 — 1차 출처 존재

- 그 주장을 뒷받침하는 **T1 또는 T2 소스가 최소 1개** 있는가 (source-tiers.md)
- T3만 있으면 → **탈락**. news-research 3단계로 돌아가 1차를 찾거나 주장을 버린다
- **강도 상한**: T2 단독 근거는 **최대 E2까지**만 올라간다. `E1`은 T1(지침 원문·기관 공식 발표) 확인이 필요하다

### 관문 2 — 교차 확인

아래에 해당하는 주장은 **서로 독립인 2개 출처**가 필요하다: 수치 · 시점 · 인과 · 최상급.

**"독립"의 뜻**: 같은 보도자료를 옮긴 기사 3개는 **출처 1개다.**

**예외 (중요)** — 이 규칙이 막으려는 것은 *2차 전달 과정에서 틀어진 수치*이지, 발표 주체가 하나뿐인 공적 통계가 아니다.

- **T1 1차 원문(통계표·원논문·기관 보도자료 원문)에서 우리가 직접 열어 확인한 수치는 단일 출처로 충분하다.** 카드에 `원문 확인: Y`를 남긴다
- 교차 확인이 필요한 것은 **2차 전달을 거친 수치**다 — 기사가 옮긴 수치, 요약 자료의 수치, 원문 미접근(`원문 확인: N`) 상태의 수치
- 2출처도 원문 확인도 없는 수치는 **화면에 숫자로 띄우지 않는다.** 서술로만 쓰거나 주장을 버린다
- 그 밖의 일반 주장(지침 내용, 해부학적 사실)은 T1/T2 1개로 충분하다

### 관문 3 — 정정·철회 확인 (실행 절차를 지킨다)

"확인했다"는 말만 만들지 않는다. 아래 네 경로 중 **실제로 수행한 것을 카드에 기록한다.**

1. PubMed에서 해당 논문 페이지의 `Retracted` / `Erratum in` / `Expression of Concern` 배너 확인
2. Retraction Watch Database 검색
3. 저널 페이지의 correction notice 확인
4. 기관 소스는 해당 기관 사이트에서 "정정"·"해명" 검색 + 같은 주제 후속 보도 검색

- 하나도 수행하지 못했으면 `정정 확인: 미실시`로 남기고 **그 카드를 훅·핵심 카드로 쓰지 않는다**
- 정정이 발견되면 → 탈락, 또는 "정정된 내용"을 새 주장으로 다시 분해

### 관문 4 — 표현 가능 여부

**references/claim-rules.md를 읽고** 그 주장을 한국어로 어떻게 말할 수 있는지 확정한다. 말할 방법이 없으면(어떻게 써도 의료 단정이 되는 주장) → 탈락.

### 관문 5 — 수치 해석 (가장 자주 놓치는 관문)

근거가 강해도 수치가 무엇을 재는 값인지 틀리면 오정보가 된다. claim-rules.md 3절을 적용한다.

- **수치 유형**을 원문에서 확인한다: 절대위험 / 상대위험(RR·RRR) / 오즈비(OR) / 해저드비(HR) / 평균차(MD·SMD) / 발생률 / NNT. **확인하지 못하면 수치 카드로 승격하지 않는다**
- 상대값이면 **기저값(대조군 절대 발생률)을 원문에서 찾는다.** 못 찾으면 화면에 %로 띄우지 않는 제약을 카드에 명시
- **임상적 유의성**을 확인한다 — 이 항목이 빠지면 "출처도 있고 숫자도 맞는데 결론이 틀린" 카드가 만들어진다:
  - MCID(최소 임상적 중요 차이)를 넘었는가 / 저자가 "clinically meaningful"이라고 했는가
  - 원문이 **"임상적으로 의미 있는 수준이 아니다"**라고 밝혔으면 → 카드에 `임상적 유의성: 미달(원문 명시)`을 적고, **허용 화법에 "수치와 그 사실을 같은 문장에 넣는다"를 못 박는다.** 수치만 떼어 자막에 띄우는 것을 금지 화법에 적는다
  - 원문에서 확인 못 했으면 `임상적 유의성: 미확인` — 크기를 단정하지 않는 제약을 카드에 명시
- **연구 설계**를 확인한다: RCT / 코호트 / 환자-대조군 / 단면 / 동물·세포 / 지침·합의 / 체계적 문헌고찰·overview. 관찰연구면 **인과 서술 금지**를 카드에 명시
- **GRADE 확실성**을 확인한다 (high / moderate / low / very low). 명시돼 있으면 **3단계 강도 판정에서 설계보다 우선한다**
- **연구 대상**을 확인한다. 채널 타깃(기본 4050 일반인)과 연령·성별·건강 상태가 명확히 다르면 → 대상을 문장에 넣어도 **훅·핵심 카드로 승격하지 않는다** (배경 설명용 카드로만)

## 3단계: 주장 강도 판정 (E1~E4 + 근거부재)

**이 값이 대본에서 쓸 수 있는 동사를 결정한다.**

| ID | 강도 | 근거 수준 | 대본 화법 |
|---|---|---|---|
| `E1` | 확립 | **문서화된 진료지침·기관 공식 권고** (T1 필수). 카드에 `지침명 + 발행 연도 + 해당 권고 문구`를 적는다 | "권고합니다({지침명})", "~로 알려져 있습니다" |
| `E2` | 근거있음 | 체계적 문헌고찰·다수 RCT (또는 T2 단독 근거의 상한) | "여러 연구에서 ~한 결과가 나왔습니다" |
| `E3` | 예비 | 단일 연구·소규모·관찰연구·동물실험 | "한 연구에서는 ~" + **"아직 확정된 결론은 아닙니다" 병기 필수** |
| `E4` | 주장 | 전문가 개인 의견·기관 입장 표명 | "{대학·병원} {진료과} ○○ 교수는 ~라고 말합니다" — **소속은 대학·병원이지 학회가 아니다** |

**근거 확실성이 설계보다 우선한다 (필수)**

설계만 보고 등급을 매기면 **"체계적 문헌고찰이니까 E2"**가 되는데, 모은 근거 자체가 부실하면 결론은 여전히 약하다. 실제 사례에서 확인된 규칙이다.

| 원문의 GRADE 확실성 | 강도 상한 |
|---|---|
| high | `E2` (E1은 지침·기관 권고일 때만) |
| moderate | `E2` |
| **low · very low** | **`E3`** — 설계가 체계적 문헌고찰·overview여도 |

- **저자가 결론에서 "inconclusive"·"uncertain"이라고 밝혔으면** 그 카드는 **`근거부재`에 준해 다룬다.** 어떤 통념도 뒤집는 근거로 쓰지 않고 "아직 결론이 나지 않았다"까지만 말한다. 카드의 금지 화법에 "뒤집혔다/밝혀졌다"를 명시한다
- 저자보다 세게 말하지 않는다 — 논문이 "의문을 제기한다"고 쓴 것을 "뒤집혔다"로 옮기지 않는다
- "교과서 수준", "다들 아는 사실"은 E1의 근거가 아니다. **문서를 지목하지 못하면 E1이 아니다**
- `E3`·`E4`를 **일반화해서 말하지 않는다** — "연구에 따르면 좋습니다"는 E3를 E2처럼 말한 것으로, 이 스킬이 잡아야 할 대표적 결함이다
- 동물·세포 실험은 E3 안에서도 별도로 `(동물실험)` 표시
- **강도는 사용자 요구로 바뀌지 않는다.** "E2로 해달라"고 해도 근거가 E3면 E3다

### `근거부재` 카드 (통념 반박의 표준 경로)

민간 통념은 진료지침이 명시적으로 반박하지 않는 경우가 대부분이다. "**반대가 참이다**"를 증명할 수 없어도 "**그렇다는 근거가 확인되지 않는다**"는 말할 수 있고, `myth` 유형의 실제 경로가 이쪽이다.

```
### F3  [유형: 근거부재]
확인 대상 통념: "○○ 성분이 연골을 재생시킨다"
확인 범위: 식약처 건강기능식품 기능성 인정 목록(2026-08) · Cochrane · PubMed 체계적 문헌고찰 검색
확인 결과: 해당 기능성 인정 없음 / 사람 대상 SR 없음
강도: E1(부재 확인) — **확인 범위를 문서화했을 때만 E1**
허용 화법: "지금 인정된 범위는 ○○까지입니다", "사람을 대상으로 한 연구는 아직 확인되지 않습니다"
금지 화법: "효과가 없습니다"(부재 ≠ 반증), "가짜입니다"
```

- **확인 범위(무엇을 어디까지 찾아봤는지)를 적지 않은 근거부재 카드는 만들지 않는다.** 그것 없이는 "안 찾아본 것"과 구별되지 않는다

### 경고 카드 (`W-visit` / `W-urgent`) — 근거가 필요하다

건강 주제에서 "이럴 땐 병원에 가야 한다"는 카드를 **반드시 하나 만든다.** 이 카드는 대본에서 생략할 수 없다.

**그러나 가장 강하게 강제되는 항목이 가장 검증되지 않는 일이 없어야 한다.** 경고 카드도 팩트 카드이며 **T1/T2 출처가 필수**다.

| 등급 | 언제 | 화면 처리 |
|---|---|---|
| `W-visit` | 진료 권고 수준 (통증 지속·기능 제한 등) | 자막 1회 이상 |
| `W-urgent` | **즉시 119** (급성 흉통, 편측 마비·언어장애, 자살 사고 등) | **전체 정지 화면 + 최대 폰트 + 나레이션 필수** |

- 주제가 **심혈관·뇌혈관·정신건강**이면 `content_type`과 무관하게 `W-urgent` 카드를 **강제 생성**한다
- 정신건강 주제면 자살예방상담전화 **109** 안내를 필수 삽입 문구로 지정한다
- **폴백**: 지침에서 red flag 목록을 확인하지 못하면 **구체적 증상을 나열하지 않는다.** 비특이적 일반 권고만 쓴다 — "증상이 2주 이상 이어지거나 점점 심해지면 진료를 받아보세요." **근거 없는 구체적 red flag보다 근거 있는 일반 권고가 안전하다**

## 4단계: 시의성·유효기한 확정

카드마다 계산한다 (`collected_at` 기준). **research의 값은 참고용이며 이 스킬의 값이 정본이다.**

| 등급 | 원문 발행일 | 화법 허용 범위 | 기본 유효기한 |
|---|---|---|---|
| `A` | 7일 이내 | "이번 주", "며칠 전" | 수집일 + 30일 |
| `B` | 30일 이내 | "최근", "이번 달" | 수집일 + 60일 |
| `C` | 90일 이내 | 시점 표현 자제 | 수집일 + 180일 |
| `D` | 90일 초과 | **속보·시점 화법 금지.** 상시 정보로만 | 상시 |

**`expiry_date` 산정 — 사유 우선**

1. 소재에 **명시적 시점**이 있으면 그것이 만료일이다: 정책 시행일 · 신청 마감일 · 통계 다음 발표 예정일 · 지침 개정 예고일
2. 없을 때만 위 기본값을 쓴다
3. 카드에 **`만료 사유`**를 함께 적는다

**세트 값**
- 세트 `expiry_date` = 카드들의 `expiry_date` 중 **가장 이른 날짜** = **업로드 마감일**
- 세트 `content_expiry` = 게시된 영상의 유효 종료일. 기본은 `expiry_date + 90일`, 정책·통계 소재는 그 시점 이후 무효 → publish-kit의 정정 점검 예약에 쓰인다
- 세트 `freshness`는 **훅과 제목에만 적용된다.** 핵심 카드(훅에 쓰는 카드)의 등급을 따르고, 어느 카드가 핵심인지 명시한다
- **문장별 시점 화법은 세트 등급이 아니라 그 문장의 근거 카드 등급을 따른다** — 핵심 카드 하나만 최신인 영상이 전체를 최신인 척하지 못하게 하는 규칙이다

**만료 규칙**: 제작 중 `expiry_date`를 지나면 이 스킬을 다시 돌린다. storyboard·video-gen·assemble·publish-kit이 모두 시작 전에 만료를 확인한다.

## 5단계: 팩트 카드 산출 (계약 산출물)

```
🧾 팩트 카드 세트
content_type: myth  (research 제안값 — 확정은 news-script)
collected_at: 2026-08-25 / 세트 freshness: B / expiry_date: 2026-10-24 / content_expiry: 2027-01-22
핵심 카드: F2
훅·제목 시점 화법: 허용("최근"까지)

### F1
주장: 무릎에서 나는 소리(염발음) 자체는 대부분 병적 상태를 뜻하지 않는다
강도: E1 (확립) — 근거 문서: 대한정형외과학회 「무릎 염발음 안내」(2025)
출처: S4(T2, 대한정형외과학회, 2025-11-03)
원문 확인: Y / 정정 확인: 기관 사이트 검색 (2026-08-25)
연구 설계: 지침·합의 / GRADE 확실성: — / 연구 대상: 일반 성인
수치 유형: — / 임상적 유의성: —
freshness: D (상시 정보) / 만료 사유: 지침 개정 시
화면 표기 문구: "출처: 대한정형외과학회(2025.11)"   ← 24자 이내
허용 화법: "~로 알려져 있습니다"
금지 화법: "괜찮습니다"(단정), "병이 아닙니다"(진단)
동반 필수 카드: F5 (경고)

### F2
주장: …
```

**필드 계약 — 아래에 없는 필드를 새로 만들지 않는다.**

| 필드 | 만드는 곳 | 쓰는 곳 |
|---|---|---|
| `주장` | 이 스킬 | news-script 문장의 사실 근거 |
| `강도` (E1~E4 / 근거부재) | 이 스킬 | **script가 쓸 어미를 결정** · auditor 판정 |
| `근거 문서` (E1일 때 지침명·연도·권고 문구) | 이 스킬 | auditor의 E1 판정 검증 |
| `출처` (S ID + 등급 + 발행처 + 발행일) | 원장에서 그대로 | **publish-kit 출처 목록** · auditor 대조 |
| `원문 확인` / `정정 확인` | 관문 2·3 수행 기록 | auditor가 "확인했다는 말"을 검증 |
| `연구 설계` / `연구 대상` / `수치 유형` / `기저값` | 관문 5 | **script의 인과·대상·수치 서술 제약** · auditor |
| `GRADE 확실성` | 관문 5 (원문에 있으면) | **3단계 강도 상한을 결정한다** · auditor의 강도 검증 |
| `임상적 유의성` (충족 / 미달(원문 명시) / 미확인) | 관문 5 | script가 수치를 말할 때 함께 넣을 문장 · auditor 수치 해석 검수 |
| `freshness` / `만료 사유` | 4단계 | **문장별 시점 화법** · publish-kit · auditor |
| `화면 표기 문구` | 이 스킬 (24자 이내) | **storyboard 출처 크레딧 컬럼에 그대로 들어간다** |
| `허용 화법` / `금지 화법` | claim-rules.md 적용 결과 | script 작성 규칙 · auditor 표현 검사 |
| `동반 필수 카드` | 이 스킬 | **storyboard 씬 매핑표가 동반 배치를 검사한다** |

**`화면 표기 문구` 생성 규칙 (24자 이내 — 크레딧 레이어 제한)**
- 기관 소스: `출처: {기관명}({YYYY.M})`
- 학술 소스: `출처: {저널 약칭}({YYYY})`
- 24자를 넘으면 날짜 → 연도 → 약칭 순으로 줄인다. **줄여도 발행처는 남긴다** (publish-kit 출처 목록과 대응돼야 한다)

## 6단계: 탈락 목록 (생략 금지)

통과하지 못한 주장을 **사유와 함께** 남긴다. 이 목록이 없으면 다음 단계에서 같은 주장이 슬며시 되살아난다. **이 목록은 news-script와 news-auditor까지 전달된다.**

```
🚫 사용 불가 주장
| 주장 | 탈락 관문 | 사유 |
|---|---|---|
| "○○ 성분이 연골을 재생시킨다" | 관문 1 | 1차 출처 없음 — 제조사 발표(T4)뿐 |
| "무릎 통증 90%는 ○○ 때문" | 관문 2 | 수치 교차 확인 실패 (같은 보도자료 기사 3건 = 출처 1개, 원문 미접근) |
| "이 운동을 하면 수술을 피할 수 있다" | 관문 4 | 어떤 표현으로도 의료 단정을 벗어나지 못함 |
| "○○하면 위험이 50% 준다" | 관문 5 | 상대위험만 보고, 기저값 원문 미확인 |
```

## 금지사항

- **원문을 열지 않고 검증했다고 말하지 않는다.** 접근 못 한 소스는 `원문 확인: N`으로 남기고 그 소스만으로 카드를 만들지 않는다
- 수치를 기억이나 추정으로 채우지 않는다. 원문에 없는 자릿수를 만들지 않는다 (반올림은 명시)
- 검색 결과 스니펫끼리 비교해 "2개 출처 확인"이라고 하지 않는다 — 스니펫은 같은 원문의 복사본인 경우가 대부분이다
- 사용자가 원하는 결론에 맞춰 강도를 올리지 않는다
- 근거 없는 red flag를 지어내지 않는다 (경고 카드 폴백 규칙)
- 개별 시청자에게 진단·처방으로 읽히는 문장을 카드 화법에 넣지 않는다

## 다음 단계 (체이닝)

체인 위상: **news-research → news-verify → news-script → news-storyboard → news-video-gen(AI 생성 시) → news-assemble → news-publish-kit**

카드 세트가 확정되면: "이 팩트 카드로 쇼츠 대본을 쓸까요?" → **news-script**로 진행한다.

**검증 산출물 묶음** — 아래 넷을 하나의 묶음으로 취급하며, **script 이후 모든 스킬이 이 묶음을 그대로 나른다** (publish-kit·auditor가 마지막에 읽는다):

1. **출처 원장** (S1, S2 … 등급·발행처·발행일·URL)
2. **팩트 카드 세트** (경고 카드 포함)
3. **탈락 목록**
4. 세트 값: `freshness` · `expiry_date` · `content_expiry` · 핵심 카드 ID

묶음이 파일로 저장돼 있으면 경로를, 아니면 내용을 통째로 넘긴다. **중간 스킬이 임의로 일부만 넘기지 않는다.**
