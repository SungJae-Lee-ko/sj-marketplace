# 건강·뉴스 표현 규칙 (한국, 2026-08 기준)

news-verify가 관문 4·5를 판정할 때, news-script가 문장을 쓸 때, news-storyboard가 자막을 쓸 때, news-publish-kit이 카피를 쓸 때, news-auditor가 검수할 때 **공통으로 쓰는 유일한 표현 기준**이다.

## 0. 우리가 어떤 규제를 받는가

**우리 채널도 의료광고 규제의 적용을 받는다.** 적용 방식이 병원과 다를 뿐이다. 흔한 오해가 "우린 의료인이 아니니 상관없다"인데, 의료법 제56조 제1항의 문언은 정확히 그 반대다.

| 규범 | 적용 대상 | 우리에게 미치는 영향 |
|---|---|---|
| **의료법 제56조 제1항** | **"의료인등이 아닌 자"** — 즉 우리 채널이 직접 수범자다 | 의료행위·의료기관·의료인에 관한 정보를 소비자에게 알리는 행위가 "의료광고"로 평가되면 **그 자체가 금지**된다. 위반 시 제89조 제1호 — **1년 이하 징역 또는 1천만원 이하 벌금.** 특정 병원·의원·의료인을 지목해 홍보·추천·연결하지 않는 것이 실무 방어선이다 |
| **의료법 제56조 제2항 제10호** | 의료광고를 하는 자 | **기사(記事) 또는 전문가 의견 형태로 표현되는 광고 금지.** 우리 포맷(기사형 해설 + E4 전문가 인용)에 협찬이 붙으면 정면으로 걸린다 |
| **의료법 제27조 제3항** | **누구든지** | **영리 목적 환자 소개·알선·유인 금지.** 병원 링크·상담 연결·할인 코드가 붙는 순간 발동한다 — 우리 포맷에서 가장 현실적인 위험 |
| **의료법 제27조 제2항** | 의료인이 아닌 자 | 의사·치과의사·한의사·조산사·간호사 명칭 또는 **이와 비슷한 명칭 사용 금지.** 채널명·화자 페르소나에 "○○ 닥터", "건강 주치의"를 쓰지 않는다 |
| **의료법 제27조 제1항** | 누구든지 | 무면허 의료행위. 시청자 개인을 진찰·처방하는 실질이면 위험하다 |
| **식품 등의 표시·광고에 관한 법률 제8조 제1항** | **누구든지 (판매·제휴 여부와 무관)** | 특정 식품·성분을 지목하며 **질병 예방·치료 효능이 있는 것으로 인식할 우려가 있는** 표시·광고 금지. 제26조 — **10년 이하 징역 또는 1억원 이하 벌금.** 이 플러그인이 다루는 조항 중 형량이 가장 무겁다. 광고 정의(제2조 제10호)에 **인터넷·영상**이 명시돼 있고 영업자 요건이 없다 |
| **정보통신망법 제70조 (명예훼손)** | 누구든지 | **사실을 적시해도 성립한다.** 특정 개인·업체·채널을 지목해 "틀렸다"고 하는 순간 위험해진다 → 7절 |
| **유튜브 의료 오정보 정책** | 모든 업로더 | 예방(prevention)·치료(treatment)·부인(denial) 3범주. 보건당국·WHO 가이드에 배치되면서 **심각한 위해의 중대한 위험**을 초래하는 콘텐츠가 대상이며, 특정 질환·물질에 한정되고 교육·다큐·과학·예술(EDSA) 예외가 있다 |
| **유튜브 — 오해를 일으키는 메타데이터·썸네일** | 모든 업로더 | 제목·썸네일이 내용보다 세면 **경고가 아니라 영상 삭제 + 채널 경고**다. 본문보다 센 제목은 규칙 위반이자 정책 위반이다 |
| **유튜브 — 광고주 친화적 콘텐츠 가이드라인** | 수익화 채널 | 민감한 의료 주제·충격적 표현은 제한적 수익화(노란딱지) 대상 |
| **유튜브 — 반복적·대량 생산 콘텐츠 정책** | 수익화 채널 | AI 나레이션 + 생성 배경 + 고정 템플릿을 매일 반복하면 **수익화 자격 자체가 사라질 수 있다.** 이 플러그인의 자동화가 그 방향이므로 → 8절 |

**저작권**

- **저작권법 제28조** — 공표된 저작물은 **보도·비평·교육·연구 등**을 위하여 정당한 범위에서 공정한 관행에 합치되게 인용할 수 있다
- **저작권법 제37조** — 인용하는 자는 **출처를 명시할 의무**가 있다(저작자 실명이 표시된 저작물이면 실명까지). **이 플러그인의 출처 크레딧은 신뢰도 장치이기 이전에 법적 의무다**
- **저작권법 제7조 제5호** — "**사실의 전달에 불과한 시사보도**"는 저작물이 아니다. 기사에서 **사실만 추출해 새 문장으로 쓰는 것**이 안전한 이유가 여기에 있다(4절의 근거)
- **저작권법 제35조의5** — 저작물의 공정한 이용 일반조항

## 1. 절대 금지 표현 (어떤 강도에서도)

| 금지 | 왜 | 대체 |
|---|---|---|
| 치료된다 / 낫는다 / 완치 | 의료행위 단정 | "관리에 도움이 된다는 연구가 있습니다" |
| 예방한다 / 막아준다 | 질병 예방 효능 단정. **식품·성분을 함께 말하면 식품표시광고법 제8조①1호 직격(10년 이하 징역)** | "위험을 낮춘다는 연구 결과가 있습니다" |
| 부작용 없다 / 안전합니다 | 검증 불가 단정 | "이 방법이 맞지 않을 수 있는 경우는 ~입니다" |
| 100% / 무조건 / 반드시 낫습니다 | 절대 단정 | 수치·조건을 그대로 |
| 병원 갈 필요 없습니다 / 약 끊어도 됩니다 | **치료 중단 유도 — 최악의 위험** | "치료 중이라면 담당 의료진과 상의하세요" |
| 당신의 증상은 ○○입니다 | 원격 진단 형식 | "이런 증상이 있으면 진료를 받아보세요" |
| 특정 병원·의원·의료인 지목 안내·추천·연결 | **의료법 제56조①·제27조③** | 기관 유형까지만 ("정형외과 진료를 받아보세요") |
| 의사·닥터·주치의 등 의료인 유사 명칭을 채널·화자 이름에 사용 | **의료법 제27조②** | "○○연구소", "○○랩" |
| 의사도 모르는 / 병원이 숨기는 | 음모론 프레임 + 의료 오정보 정책 | 쓰지 않는다 |
| 기적의 / 만병통치 | 과장 | 쓰지 않는다 |
| 특정 제품·업체를 지목해 "효과 없다" | 명예훼손·업무방해 | "이 성분에 인정된 기능성 문구는 ○○까지입니다" |

## 2. 조건부 허용 (조건을 지켰을 때만)

| 표현 | 조건 |
|---|---|
| "효과가 있다" | 강도 E1~E2 + **대상 집단·조건 명시**("무릎 골관절염 환자에서") |
| 수치 인용 ("N% 감소") | 교차 확인 통과 + 화면 크레딧 + 기준 시점 + **3절의 수치 유형 규칙** |
| 특정 성분·식품 언급 | **효능 단정 금지.** 식약처 인정 기능성 문구를 벗어나지 않는다 |
| "○○에 좋다" | 강도 E1~E2에서만, "좋다"의 대상을 구체화 |
| "최초 / 처음" | 최상급 교차 확인 통과 시에만 |
| 실명 인용 ("○○ 교수") | **긍정·중립 인용에만 해당한다.** 실제 발언·공개 자료에 한하고 발언 취지를 바꾸지 않는다. 부정적 맥락의 실명 사용은 7절에서 금지 |

## 3. 수치를 말하는 규칙 (가장 자주 틀리는 곳)

근거가 강해도 **수치가 무엇을 재는 값인지 틀리면 오정보가 된다.** 강도(E)와 별개로 항상 적용한다.

### 3-1. 상대값 단독 서술 금지

`상대위험(RR)`·`상대위험감소(RRR)`·`오즈비(OR)`·`해저드비(HR)`는 **단독으로 화면에 띄우지 않는다.**

- "위험이 절반으로 줄었다"는 2%→1%일 수도 있고 40%→20%일 수도 있다. 시청자는 전자를 후자로 듣는다
- 규칙: **상대값을 말하면 절대값을 같은 문장 또는 바로 다음 문장에 병기한다**
  - ○ "위험이 절반으로 — 100명 중 2명에서 1명으로 줄었습니다"
  - ✕ "위험이 50% 낮아집니다"
- 기저값(대조군 절대 발생률)을 원문에서 확인하지 못했으면 **화면에 %로 띄우지 않는다.** 서술로만("낮아졌다는 결과가 있습니다")
- **이 규칙은 나레이션 필수**다 — 자막으로만 지나가면 무음 시청자가 상대값만 본다

### 3-2. 관찰연구는 인과로 말하지 않는다

연구 설계가 **코호트·단면·환자-대조군**이면 등급과 무관하게 인과 서술을 금지한다.

| 금지 | 허용 |
|---|---|
| "~하면 ~된다" / "~때문에" / "~덕분에" | "~와 관련이 있다는 결과" |
| "~가 ~를 줄인다" | "~한 사람들에서 ~가 더 적었습니다" |

- 관찰연구를 모은 체계적 문헌고찰도 마찬가지다 (근거 등급은 E2까지 오를 수 있으나 **인과 표현은 여전히 금지**)

### 3-3. 대상 집단을 바꿔 말하지 않는다

- 연구 대상이 65세 이상 요양시설 거주자면, 그 결과를 "50대"에게 그대로 옮기지 않는다
- 대상이 채널 타깃과 명확히 다른 카드는 **훅·핵심 카드로 쓰지 않는다** (배경 설명용으로만)

### 3-4. "통계적으로 유의"와 "실제로 의미 있다"는 다르다

수치가 0이 아니라는 것과 **사람이 체감할 만큼 크다는 것**은 별개다. 이 구분이 빠지면 "출처도 있고 숫자도 맞는데 결론이 틀린" 문장이 만들어진다.

- 원문에서 **임상적 유의성**을 확인한다: MCID(최소 임상적 중요 차이)를 넘었는가, 저자가 "clinically meaningful/relevant"라고 했는가
- 원문이 **"임상적으로 의미 있는 수준이 아니다"**라고 밝혔으면 → **그 사실을 수치와 같은 문장 또는 바로 다음 문장에 넣는다.** 수치만 떼어 자막에 띄우지 않는다
  - ○ "통증 점수가 조금 낮아지긴 했지만, 연구진은 체감할 만한 차이는 아니라고 봤습니다"
  - ✕ "통증 10.8점 감소" (자막 단독)
- MCID를 원문에서 확인하지 못했으면 **"얼마나 좋아지는지는 이 연구만으로 말하기 어렵습니다"**로 처리하고, 크기를 단정하지 않는다

## 4. 강도별 어미 사다리

| 강도 | 쓸 수 있는 형태 (회전해서 쓴다) | 쓰면 안 되는 형태 |
|---|---|---|
| `E1` 확립 | "~를 권고합니다({지침·기관명})" / "~로 알려져 있습니다" / "지금 기준은 ~입니다" | "치료됩니다" |
| `E2` 근거있음 | "도움이 된다는 연구가 있습니다" / "여러 연구에서 ~한 결과가 나왔습니다" / "~한 쪽이 더 나았다는 결과입니다" / "지금까지 나온 연구는 ~쪽입니다" | "~합니다"(사실 단정) |
| `E3` 예비 | "한 연구에서는 ~" + **"아직 확정된 결론은 아닙니다" 병기** | "연구에 따르면 좋습니다"(일반화) |
| `E4` 주장 | "{대학·병원} {진료과} ○○ 교수는 ~라고 말합니다" — **소속은 대학·병원이지 학회가 아니다** (학회는 직역: "대한○○학회 ○○위원") | 주어 없는 "전문가들은 말합니다" |
| `근거부재` | "지금 인정된 범위는 ~까지입니다" / "사람을 대상으로 한 연구는 아직 확인되지 않습니다" | "효과가 없습니다"(부재 ≠ 반증) / "가짜입니다" |

**근거 확실성이 설계보다 우선한다 (필수)**

강도는 "무슨 설계로 했는가"만으로 정해지지 않는다. 체계적 문헌고찰이어도 **모은 근거 자체가 부실하면 결론은 약하다.**

- 원문에 **GRADE 확실성**(certainty of evidence: high / moderate / low / very low)이 명시돼 있으면 **그 값이 설계보다 우선한다**

  | GRADE 확실성 | 강도 상한 |
  |---|---|
  | high | `E2` (E1은 지침·기관 권고일 때만) |
  | moderate | `E2` |
  | low · very low | **`E3`** — 설계가 체계적 문헌고찰이어도 |

- **저자가 결론에서 "inconclusive(결론을 내리기 어렵다)"·"uncertain"이라고 밝혔으면** 그 카드는 `근거부재`에 준해 다룬다. 즉 **어떤 통념도 뒤집는 근거로 쓰지 않고**, "아직 결론이 나지 않았다"까지만 말한다
- 저자보다 세게 말하지 않는다 — 논문이 "의문을 제기한다"고 쓴 것을 우리가 "뒤집혔다"로 옮기지 않는다
- 동물·세포 실험은 E3 안에서도 별도다: **"동물실험 단계"임을 문장 안에 넣는다**
- 프리프린트(심사 전)는 "아직 심사를 거치지 않은 연구"임을 밝힌다
- 하나의 어미를 영상 내내 반복하지 않는다 — 위 목록을 회전한다

## 5. 인용·저작권 규칙

- **기사 문장을 그대로 옮기지 않는다.** 사실(수치·발표 내용)만 가져와 우리 문장으로 다시 쓴다 — 저작권법 제7조 제5호에 따라 사실 자체는 저작물이 아니지만 **기자가 쓴 문장은 저작물이다**
- 기사 제목·본문 캡처를 화면에 띄우지 않는다. **언론사 로고·지면 이미지·기자명도 넣지 않는다** (AI로 유사하게 그리는 것도 금지 — 가짜 기사 이미지가 된다)
- 짧은 직접 인용(한 문장 이내)은 **따옴표 + 발화자·매체 명시**로 처리한다
- **인용에는 출처 명시 의무가 따른다** (저작권법 제37조) — 화면 크레딧과 설명란 출처 목록이 그 이행이다
- 사진·영상은 원칙적으로 쓰지 않는다. 공공누리 제1유형 등 이용 조건이 명시된 공공저작물만, 조건에 맞춰 표기하고 쓴다
- 논문 그림·표를 그대로 쓰지 않는다. 수치만 가져와 **우리가 새로 만든 자막·그래픽**으로 표현한다

## 6. 실존 인물·기관 표현

- 실존 인물의 얼굴을 AI로 생성하지 않는다 (전문가·정치인·기자 모두)
- 기관 로고를 AI로 생성하지 않는다. 크레딧은 **텍스트로만** (`출처: 질병관리청`)
- 기관이 하지 않은 말을 기관 이름으로 요약하지 않는다
- 화자 이름·채널명에 의료인 유사 명칭을 쓰지 않는다 (의료법 제27조②)

## 7. 반박 대상의 특정 금지 (명예훼손 방어)

`myth` 유형은 본질적으로 "누군가 퍼뜨린 말을 틀렸다고 하는" 콘텐츠다. **한국법에서는 사실을 적시해도 명예훼손이 성립한다.**

- **반박은 주장에 대해서만 한다.** 그 주장을 한 개인·채널·업체·병원을 특정하지 않는다
- 실명·소속·채널명·상호·제품명을 **부정적 맥락에서 쓰지 않는다** (2절의 실명 인용 조건부 허용은 긍정·중립 인용에만 적용된다)
- 얼굴·목소리·특징적 말투를 흉내 내지 않는다
- 특정 제품이 "효과 없다"고 말하지 않는다 → "이 성분에 대해 식약처가 인정한 기능성 문구는 ○○까지입니다"
- **시청자 댓글·사연은 동의 없이 인용하지 않는다.** 인용 시 닉네임·연령·지역·직업 중 2개 이상이 겹치지 않게 각색하고, 각색했음을 밝힌다

## 8. 필수 삽입 문구

| 상황 | 문구 | 위치 |
|---|---|---|
| 모든 건강 주제 영상 | "이 영상은 건강 정보 제공 목적이며, 진단·치료를 대신하지 않습니다" | 설명란 첫 3줄 + 고정댓글 |
| 증상·통증을 다루는 영상 | 경고 카드 내용 (`W-visit`) | **영상 자막 1회 이상** + 고정댓글 |
| 심혈관·뇌혈관·정신건강 주제 | 응급 신호 (`W-urgent`) | **영상 자막 + 나레이션 둘 다** (전체 정지 화면·최대 폰트) |
| 정신건강 주제 | 자살예방상담전화 **109** 안내 | 설명란 + 고정댓글 |
| 강도 `E3` 카드를 쓴 문장 | "아직 확정된 결론은 아닙니다" | 해당 문장 안 |
| 상대값 수치를 쓴 문장 | 절대값 병기 | **나레이션 필수** |
| 시의성 A·B 카드를 쓴 문장 | 발행일 표기 ("2026년 8월 기준") | 자막 또는 설명란 첫 3줄 |
| 제휴·협찬 | 해당 고지 문구 | 설명란 첫 3줄 + 고정댓글 |

## 9. 자체 점검 (산출 직후 1회 필수)

news-script(대본·나레이션), news-storyboard(**자막 컬럼**), news-publish-kit(제목·설명·고정댓글)이 각각 산출 직후 실행하고 결과를 산출물에 적는다. 하나라도 걸리면 고치고 다시 점검한다.

1. 1절 금지 표현이 하나라도 있는가 (**자막·제목까지 포함** — 나레이션만 보지 않는다)
2. E3·E4 카드의 문장이 일반화돼 있지 않은가. E4에 발화자·소속이 있는가
3. **상대값 수치를 절대값 없이 말하지 않았는가**
4. **원문이 "임상적으로 의미 있는 수준이 아니다"라고 한 수치를 그 사실 없이 띄우지 않았는가**
5. **관찰연구 기반 카드를 인과로 말하지 않았는가**
6. **연구 대상 집단을 바꿔 말하지 않았는가**
7. **GRADE 확실성이 low·very low인 근거로 통념을 뒤집지 않았는가. 저자보다 세게 말하지 않았는가**
8. 수치를 말하는데 화면 크레딧이 없는가
9. 경고 카드가 영상 안에 실제로 들어갔는가 (`W-urgent`면 나레이션에도)
10. 시점 화법이 **그 문장의 근거 카드** freshness가 허용하는 범위 안인가
11. 특정 개인·업체·병원을 지목하지 않았는가 (7절)
12. 특정 제품·성분을 언급하면서 효능을 단정하지 않았는가
13. 탈락 목록의 주장이 되살아나 있지 않은가
