# Changelog — shopping-shorts

## 0.7.0 (2026-08-24)

v0.6.0 전수 품질 감사에서 나온 미해결 16건을 4개 근인으로 묶어 수정한 릴리스.

- **feat: 콘텐츠 유형(`content_type`)을 체인 1급 개념으로 승격** — 판매형(`sales`) / 습관·정보형(`habit`)
  - shorts-script에 유형 판별 단계 신설, 유형별 필수 5단계 구조 병기 (습관형: 훅→통념 깨기→방법→근거·주의→실행 CTA)
  - `[습관·정보형]` 카테고리 브리프 신설 — 의료 단정 금지 표현, 안전 고지 필수 규칙, 동작 최대 3개 제한
  - 스토리보드 씬 비중 규칙 분기: sales=상품 클로즈업 40%, habit=동작 시연 40% (+ 정면·측면 2각도, ❌/⭕ 대비 배치)
  - shorts-auditor 판정 기준 분기 — 습관형에 상품 클로즈업 비중을 요구해 무조건 FAIL 내던 문제 해소
  - publish-kit CTA·고지 요건 분기
- **feat: 스킬 간 데이터 계약을 산문에서 고정 필드로**
  - 스토리보드 씬 표를 **고정 8컬럼**으로 확정 — `나레이션` 컬럼 신설(기존에 누락되어 조립 단계가 나레이션을 받을 수 없었음), `person_group` 컬럼 신설
  - `person_group`(P1·P2…)이 스토리보드 → video-gen 앵커 스틸 관리 → auditor 프레임 대조까지 같은 ID로 관통
  - 조립 지시서 JSON에 `content_type`·`person_group`·`narration`·`narration_file` 필드 추가
  - 훅 패턴에 `H1`~`H8` 고정 ID 부여 — 목록 순번 참조(④ 등)를 걷어내 순서 변경 시 조용히 어긋나던 문제 해소
- **feat: 나레이션 파이프라인 신설**
  - shorts-script가 나레이션 음절 수 기준으로 **씬 시간표**를 확정 (`음절수 ÷ 4.5 + 0.4초`), 이후 단계는 받아쓰기만 한다
  - shorts-assemble에 나레이션 수집 절차 신설 (폴더 스캔·씬 매칭·TTS 생성 제안·미확보 처리)
  - 오디오 믹스를 3층 순서로 명시: 나레이션 → 클립 오디오 덕킹 → BGM, -14 LUFS 목표
  - 길이 정합 규칙 신설: ±5% atempo / 5~15% 클립 trim 조정 / 15% 초과는 자동 처리 금지하고 사용자 선택
- **fix: 체인 위상 통일**
  - 실촬영 분기가 shorts-assemble을 건너뛰고 publish-kit으로 직행하던 누수 수정 — 실촬영도 자동 조립 경로로
  - shorts-video-gen의 "조립은 사용자가 편집 앱(CapCut 등)에서 수행" 잔존 문장 삭제 (바로 아래 자동 조립 안내와 모순)
  - publish-kit이 자신을 3스킬 체인의 종점으로 소개하던 description·본문 갱신
  - 전 스킬 "다음 단계" 섹션에 동일한 체인 위상 문장 배치
- **fix: 제휴 고지 요건 명확화** — 판매 형태별 고지 표 신설. 제휴·유료광고는 **설명란과 고정댓글 양쪽 모두 필수**, 설명란 고지는 첫 3줄 안에. auditor도 양쪽 존재를 검사
- **fix: 버전 단일화** — plugin.json·marketplace.json·전 스킬·전 테스트를 0.7.0으로 통일. 스킬별 개별 버전이 실제 수정 시점과 어긋나 최신 여부를 판단할 수 없던 문제 해소
- docs: 플러그인 README 전면 재작성 (v0.3.0 3스킬 체인 기재 상태였음). 체인 정본 다이어그램·체인이 나르는 값 3가지·재설치 후 새 세션 안내 추가
- test: 신규 케이스 18건 추가 (습관형 생성·유형 혼합·씬 시간표·고정 컬럼·person_group 다중 그룹·나레이션 스캔/부재/길이 초과·양쪽 고지)
