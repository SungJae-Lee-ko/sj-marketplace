# Changelog — shopping-shorts

## 0.7.1 (2026-08-24)

v0.7.0 재감사(실행 시뮬레이션·체인 계약·테스트/메타 3렌즈)에서 확인된 미해결 결함을 3개 근인으로 묶어 수정한 릴리스.

- **fix: 씬 시간표를 씬 단위 계약으로 확정** (근인 — 시간 계약이 반쪽이었음)
  - shorts-script는 **문장 단위 나레이션 시간표**(N1, N2 … 음절수·예상 초)까지만 만든다 — 씬은 아직 없으므로 "씬 시간표"를 만들지 않는다
  - **씬 단위 씬 시간표는 shorts-storyboard가 확정한다** (씬·구간·포함 문장·예상 초·배정 초·실측 초). 문장은 씬 경계로 쪼개지 않는다
  - 기존의 구간 단위 5행 표 → 씬 7-12개에 배분할 규칙이 없어 storyboard·assemble이 받아쓸 수 없던 문제 해소
  - 실행 주체가 없던 "TTS 실측 후 표 갱신"을 삭제하고, **선(先) 나레이션 생성**을 storyboard 단계의 권장 절차로 명시 (클립 과금 전에 실측 확정)
  - 길이 허용 오차 기준을 shorts-assemble의 [길이 정합 규칙] 하나로 일원화 — script의 "±5% 초과 시 문장 수정"과 assemble의 "5~15%는 trim 조정"이 같은 상황에 반대로 지시하던 모순 제거
  - assemble 입력 절차에 씬 시간표를 1급 입력으로 명시하고, **자막 타이밍의 출처를 씬 구간으로 확정** (자막 컬럼에는 시간 정보가 없어 생산자가 부재하던 문제)
  - 실촬영 경로: `trim_to` 생산자가 없던 문제를 "씬 시간표 배정 초만큼 + 사용자 확인"으로 정의하고, `content_type`·`sales_form`·씬 시간표 인계를 스토리보드 체이닝 문장에 명시
- **fix: 습관·정보형(`habit`)이 shorts-video-gen에 도달하도록 분기 신설** (근인 — 3단계에서 좌초하던 문제)
  - 사전 조건의 "A자료 업로드"를 **`sales` 한정 게이트**로 축소. `habit`은 A자료가 없는 것이 정상이며 **캐스팅 시트가 그 자리를 대신한다**
  - [습관형 생성 경로] 신설: 캐스팅 시트 기반 그룹별 앵커 스틸 → 동작 1개당 **시작·정점 2스틸 교차컷** → 횟수·시간은 카운트 자막으로 전달 → 실촬영 거부 시 다이어그램형 폴백
  - "행위 정점 스틸 + 저위험 모션"만으로는 동작의 횟수·시간이 화면에 남지 않던 문제 해소
  - shorts-script description에 습관형 진입 문구 추가 (기존 트리거 5개가 전부 판매형 문구였음), 산출 길이 표기를 15-60초(기본 30-45초)로 정정
- **fix: 조립·검수 기준 일원화** (근인 — 같은 값이 문서마다 달랐음)
  - `atempo` 허용 범위를 **0.95~1.05 하나로 통일** (assemble 표 0.95~1.05 / assemble 본문 0.9~1.1 / auditor 0.9~1.1로 3원화돼 있었음)
  - 총 길이 검증 기준을 **"조립 리포트의 최종 씬 시간표(조정 반영본) ±0.5초"**로 재정의 — 규칙이 허용한 5~15% trim 조정이 auditor FAIL을 유발하던 모순 제거
  - auditor 검수 시점을 "발행 키트 산출 후, 업로드 직전"으로 통일 (description은 publish-kit 이전이라 했으나 본문에 §4 발행 키트 검수가 있어 서로 어긋났음)
  - 스토리보드 예시 씬 2를 교체 — 자기 규칙(3초 룰·행위 정점 1프레임)과 video-gen 금지(랠리 연출)를 동시에 위반하던 예시였다. 예시는 규칙보다 강하게 모방되므로 규칙 준수 예시로 대체하고 금지사항에 명문화
  - auditor가 실촬영 스토리보드에도 요구하던 연속 테이크 문구(AI 프롬프트 전용)를 **AI 생성 씬 한정**으로 수정
- **feat: 판매 형태(`sales_form`)를 체인이 나르는 4번째 값으로 승격**
  - 열거값 통일: `own` / `resell` / `affiliate` / `sponsored` / `null`(habit) — 기존에 reference-analysis는 3지선다(유료광고 없음), publish-kit 고지 표는 리셀·위탁 행 없음으로 서로 달랐다
  - `affiliate`·`sponsored`의 **제품 AI 재생성 금지** 제약이 storyboard·video-gen까지 전달된다 (쿠팡 상세 이미지를 그대로 i2v에 넣는 위험 차단)
  - publish-kit 고지 표에 `resell` 행 추가, `habit` + 제휴 링크 유입 시 1회 확인 절차 명문화 (테스트만 있고 스펙에 없던 동작)
- **fix: 죽은 필드 정리 — 조립 지시서의 모든 필드에 생산자·소비자를 표로 명시**

  - `review`: **assemble이 `pass`가 아닌 클립을 조립에서 제외**하는 게이트로 소비자 지정 (기존엔 검수 실패 클립이 그대로 완성본에 실렸다)

  - `storyboard_ref`·`character_id`: 용도 정의. `scene_timing`·`sales_form`·`note` 필드 신설
- fix: `shorts-producer` 에이전트의 `tools` 열거 제거 — 영상 생성·TTS MCP 도구가 목록에서 빠져 자기가 주행 선언한 생성 단계를 실행할 수 없었다
- fix: `person_group` 반려 규칙을 "인물 씬이 있는데 ID가 빈 경우"로 한정 — 인물 0명 기획(전 씬 `—`)을 오판해 되돌리던 문제
- fix: shorts-script의 "씬 길이를 5초 배수로" 문장이 3초 훅·2-5초 씬 규칙과 충돌하던 것을 "생성은 5초, 사용은 트림"으로 정정

## 0.7.0 (2026-08-24)

v0.6.0 전수 품질 감사에서 나온 미해결 16건을 4개 근인으로 묶어 수정한 릴리스.

- **feat: 콘텐츠 유형(`content_type`)을 체인 1급 개념으로 승격** — 판매형(`sales`) / 습관·정보형(`habit`)
  - shorts-script에 유형 판별 단계 신설, 유형별 필수 5단계 구조 병기 (습관형: 훅→통념 깨기→방법→근거·주의→실행 CTA)
  - `[습관·정보형]` 카테고리 브리프 신설 — 의료 단정 금지 표현, 안전 고지 필수 규칙, 동작 최대 3개 제한
  - 스토리보드 씬 비중 규칙 분기: sales=상품 클로즈업 40%, habit=동작 시연 40% (+ 정면·측면 2각도, ❌/⭕ 대비 배치)
  - shorts-auditor 판정 기준 분기 — 습관형에 상품 클로즈업 비중을 요구해 무조건 FAIL 내던 문제 해소
  - publish-kit CTA·고지 요건 분기
- **feat: 스킬 간 데이터 계약을 산문에서 고정 필드로**
  - 스토리보드 씬 표를 **고정 8컬럼**으로 확정 — `나레이션` 컬럼 신설(기존에 누락되어 조립 단계가 나레이션을 받을 수 없었음), `person_group` 컬럼 신설
  - `person_group`(P1·P2…)이 스토리보드 → video-gen 앵커 스틸 관리 → auditor 프레임 대조까지 같은 ID로 관통
  - 조립 지시서 JSON에 `content_type`·`person_group`·`narration`·`narration_file` 필드 추가
  - 훅 패턴에 `H1`~`H8` 고정 ID 부여 — 목록 순번 참조(④ 등)를 걷어내 순서 변경 시 조용히 어긋나던 문제 해소
- **feat: 나레이션 파이프라인 신설**
  - shorts-script가 나레이션 음절 수 기준으로 **씬 시간표**를 확정 (`음절수 ÷ 4.5 + 0.4초`), 이후 단계는 받아쓰기만 한다
  - shorts-assemble에 나레이션 수집 절차 신설 (폴더 스캔·씬 매칭·TTS 생성 제안·미확보 처리)
  - 오디오 믹스를 3층 순서로 명시: 나레이션 → 클립 오디오 덕킹 → BGM, -14 LUFS 목표
  - 길이 정합 규칙 신설: ±5% atempo / 5~15% 클립 trim 조정 / 15% 초과는 자동 처리 금지하고 사용자 선택
- **fix: 체인 위상 통일**
  - 실촬영 분기가 shorts-assemble을 건너뛰고 publish-kit으로 직행하던 누수 수정 — 실촬영도 자동 조립 경로로
  - shorts-video-gen의 "조립은 사용자가 편집 앱(CapCut 등)에서 수행" 잔존 문장 삭제 (바로 아래 자동 조립 안내와 모순)
  - publish-kit이 자신을 3스킬 체인의 종점으로 소개하던 description·본문 갱신
  - 전 스킬 "다음 단계" 섹션에 동일한 체인 위상 문장 배치
- **fix: 제휴 고지 요건 명확화** — 판매 형태별 고지 표 신설. 제휴·유료광고는 **설명란과 고정댓글 양쪽 모두 필수**, 설명란 고지는 첫 3줄 안에. auditor도 양쪽 존재를 검사
- **fix: 버전 단일화** — plugin.json·marketplace.json·전 스킬·전 테스트를 0.7.0으로 통일. 스킬별 개별 버전이 실제 수정 시점과 어긋나 최신 여부를 판단할 수 없던 문제 해소
- docs: 플러그인 README 전면 재작성 (v0.3.0 4스킬 체인 기재 상태였음). 체인 정본 다이어그램·체인이 나르는 값 3가지·재설치 후 새 세션 안내 추가
- test: 신규 케이스 19건 추가 (습관형 생성·유형 혼합·씬 시간표·고정 컬럼·person_group 다중 그룹·나레이션 스캔/부재/길이 초과·양쪽 고지)
