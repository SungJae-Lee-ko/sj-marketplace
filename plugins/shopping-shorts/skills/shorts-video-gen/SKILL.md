# 쇼핑쇼츠 영상 생성 (Video Generation Orchestrator)

**책임 한 줄**: 확정된 스토리보드 + 레퍼런스 A자료 입력 → 씬별 [이미지 생성 → image-to-video] 체인 실행 → 검수된 씬 클립 세트 + 조립 지시서 반환.

## 사전 조건 (모두 충족해야 시작)

1. shorts-storyboard 산출물이 확정됨 (없으면 그 스킬로 먼저)
2. 영상 생성 MCP(Higgsfield 등) 연결 확인 — 없으면 씬별 프롬프트만 정리해 주고 종료
3. **생성 전 비용 추정 고지 + 사용자 승인** (아래 비용 섹션) — 승인 없이 생성 호출 금지

## 생성 파이프라인 (씬 단위 반복)

```
[Step 0] 캐릭터 일관성 결정 (시리즈물만, 아래 의사결정 트리)
   ↓
[Step 1] 씬 스틸 이미지 생성
   └─ 제품 등장 씬: 레퍼런스 A자료를 소스로 (형태 보존)
   └─ 상황/배경 씬: B자료의 무드 묘사를 프롬프트로 (B를 소스로 쓰지 않음)
   └─ 캐릭터 씬: character_id 전달 (Step 0 사용 시)
   ↓
[Step 2] image-to-video 변환
   └─ Step 1 이미지를 소스로, 모션 프리셋 적용 (아래 표)
   └─ 클립 길이: 씬 길이를 덮는 최소 클립 단위 (통상 5초)
   ↓
[Step 3] 클립 검수
   └─ 체크: 제품 형태 왜곡 / 로고 깨짐 / 손가락·글자 오류 / 씬 목적 부합
   └─ 불합격 시 재생성 1회 (프롬프트 수정 후) — 2회 실패면 해당 씬 실촬영 전환 제안
   ↓
[Step 4] 조립 지시서 산출 (아래 형식)
```

## 모션 프리셋 (씬 역할 기준 자동 매핑)

| 씬 역할 | 프리셋 | 이유 |
|---|---|---|
| 훅 (0-3초) | impact_zoom (빠른 줌인) 또는 reveal | 첫 프레임에서 시선 고정 |
| 제품 클로즈업 | orbit 또는 slow_zoom | 제품 형태를 안정적으로 보여줌 |
| 상황/사용 장면 | pan (좌우 이동) 또는 handheld | 생활감·현장감 |
| 비교/증거 | static + 화면 분할 여지 | 정보 전달은 무빙 최소화 |
| CTA | static 또는 slow_zoom_out | 자막·행동 지시가 주인공 |

사용자가 지정하면 그 값이 우선. 프리셋 이름은 연결된 MCP가 지원하는 실제 프리셋명으로 치환해 호출한다.

## 캐릭터 일관성 의사결정 트리 (Step 0, 시리즈물 전용)

```
[Q1] 쇼츠를 시리즈로 올릴 계획이고, 같은 인물/마스코트가 반복 등장하나?
   ├─ 아니오 → Step 0 skip (제품 단독 모드)
   └─ 예 → [Q2]
[Q2] 이미 등록된 캐릭터(character_id)가 있나?
   ├─ 예 → 해당 id를 모든 씬 생성에 전달
   └─ 아니오 → 캐릭터 등록을 제안 (최초 1회 비용·시간 고지) 후 등록된 id 사용
```

- 실존 인물 얼굴로 캐릭터를 만들려면 본인 동의를 확인한다. 타인·유명인 얼굴은 거절

## 비용 추정 (생성 전 필수 고지)

```
📊 생성 비용 추정
- 씬 수: N개 (스틸 N장 + 클립 N개)
- 재생성 예비: +20% 가정
- 예상 크레딧/비용: [연결된 MCP의 단가 기준으로 계산]
- 총액이 확실치 않으면 "이미지 1장+클립 1개 단가 × 씬 수 × 1.2" 범위로 제시
진행할까요? (일부 씬만 먼저 생성하는 것도 가능 — 훅 씬 1개 테스트 권장)
```

- 첫 실행이면 **훅 씬 1개만 테스트 생성 → 품질 확인 → 나머지 일괄**을 기본으로 제안한다 (전량 생성 후 스타일이 안 맞으면 비용 전액 손실)

## 출력 형식 (조립 지시서)

```json
{
  "storyboard_ref": "제품명-v1",
  "character_id": null,
  "clips": [
    {"scene": 1, "role": "hook", "duration": 5, "trim_to": "0.0-3.0",
     "motion": "impact_zoom", "source": "A자료 hero.jpg", "url": "...",
     "review": "pass"}
  ],
  "assembly": {
    "sequence": [1,2,3],
    "subtitles": "스토리보드 자막 컬럼 참조",
    "bgm_cue": "스토리보드 오디오 컬럼 참조",
    "export": "9:16 1080×1920, 씬별 trim_to 구간만 사용"
  },
  "ai_disclosure": "유튜브 업로드 시 '변경·합성된 콘텐츠' 공개 설정 필요"
}
```

- `trim_to`: 생성 클립(5초)에서 실제 씬 길이(예: 3초)만큼 잘라 쓸 구간
- 조립은 사용자가 편집 앱(CapCut 등)에서 수행 — 이 지시서가 편집 순서표 역할

## 이 스킬을 사용하지 말아야 할 때

- **스크립트·콘티가 아직 없음** → shorts-script / shorts-storyboard 먼저
- **단일 이미지·단일 클립만 필요** → 영상 생성 MCP 직접 호출이 빠름
- **실촬영으로 확정된 프로젝트** → 본 스킬 불필요, 스토리보드의 촬영 체크리스트 사용
- **상세페이지용 이미지 세트** → 본 플러그인 범위 밖 (상세페이지 이미지 전용 스킬 사용)

## 다음 단계 (체이닝)

클립 세트가 나오면: "발행용 제목·설명·해시태그를 만들까요?" → **shorts-publish-kit**으로 진행. 이때 AI 생성 사실을 publish-kit에 전달한다 (합성 콘텐츠 공개 설정 체크리스트 반영).
