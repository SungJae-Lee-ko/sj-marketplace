# 쇼핑쇼츠 스크립트 작성

유튜브 쇼츠 스크립트를 만든다. 목표는 "3초 안에 잡고, 30초 안에 설득하고, 마지막에 행동시키기".

## 모드 판별 (가장 먼저)

| 모드 | 발동 조건 | 동작 |
|------|----------|------|
| 생성 (기본) | 새 스크립트 요청 | 아래 유형 판별부터 진행 |
| 진단 | 기존 스크립트·쇼츠를 주며 평가/개선 요청 ("진단해줘", "조회수가 안 나와", "뭐가 문제야") | 맨 아래 [진단 모드] 절차로 |

## 콘텐츠 유형 판별 (생성 모드에서 두 번째로, 반드시)

**이 값(`content_type`)은 체인 전체가 나르는 값이다.** 스토리보드의 씬 설계 규칙, 검수(shorts-auditor)의 판정 기준, 발행 키트의 CTA·고지가 모두 이 값으로 분기한다. 산출물 머리에 반드시 명시한다.

| content_type | 정의 | 판별 신호 |
|---|---|---|
| `sales` (판매형) | 특정 상품을 팔거나 구매로 연결하는 콘텐츠 | 상품명·링크·가격·제휴가 입력에 있음 |
| `habit` (습관·정보형) | 파는 상품 없이 습관·운동·정보를 전달하는 콘텐츠 | 상품이 없고 동작·방법·정보가 주제 |

- 입력만으로 애매하면 **한 번 묻는다**: "이 영상, 특정 상품 구매로 연결하는 편인가요? 아니면 상품 없이 방법만 알려주는 편인가요?"
- 습관형인데 마지막에 제품을 하나 얹는 혼합 요청이면 → **판매형으로 처리**하되, 훅·구조는 습관형을 쓰고 CTA만 판매형으로 간다는 점을 사용자에게 고지한다 (제휴 고지 의무가 발생하는 쪽이 판매형이므로 안전한 쪽으로 붙인다)

## 브리프 적용 (생성 모드 공통)

**references/category-briefs.md**를 읽고 유형에 맞는 브리프를 적용한다:

- `habit` → **[습관·정보형] 브리프**. 상품 카테고리 브리프는 적용하지 않는다
- `sales` → 카테고리(뷰티/건강식품/전자/식품/일반)를 판별해 해당 브리프 적용

공통 규칙:
- 훅 우선순위·씬 아이디어·증거 구간 구성은 브리프가 기본 규칙보다 우선
- 브리프의 금지/조건부 표현은 절대 규칙 — 위반 표현이 필요해 보이면 안전 대체 표현을 쓰고 사유를 사용자에게 고지
- 건강식품·습관형 두 유형은 산출 후 금지 표현 자체 점검 1회 필수 (건강식품=기능성 단정, 습관형=의료 단정)

## 0단계: 레퍼런스 확인 (필수 질문)

작업 시작 전에 반드시 먼저 묻는다:

> "참고할 레퍼런스가 있나요? ① **제품 자료** (실사진·상세페이지·패키지 — 판매형인 경우) ② **유사 상황 자료** (경쟁 제품, 동작·상황 이미지) ③ **벤치마킹할 쇼츠 영상** (링크·스크린샷) — 있는 것만 주시면 됩니다. 없으면 기본 스타일로 진행해요."

①은 제품의 정답지(형태 보존·생성 소스), ②는 장면 영감(배경·상황만 참고), ③은 편집 문법 참고로 역할이 다르다. 받은 자료가 어느 쪽인지 애매하면 반드시 확인한다. 습관형이면 ①은 없는 것이 정상이고, 인물·장소 톤을 잡을 참고 이미지가 ②에 해당한다.

레퍼런스를 받으면 **references/reference-analysis.md**의 절차대로 분석해 스타일 프로필을 만들고, 사용자 확인 후 이후 전 단계에 적용한다. 비주얼 레퍼런스는 shorts-storyboard 단계의 AI 영상 생성 소스로 넘긴다.

## 입력 확인

사용자에게 아래 정보를 확인한다. 없으면 물어보되, 상품 URL이 있으면 웹서치/페치로 직접 조사해 채운다.

1. **주제**: (sales) 상품 이름·카테고리·가격대 / (habit) 다루는 습관·동작·정보 주제
2. **핵심 포인트**: 최대 3개. (sales) 셀링포인트 / (habit) 전달할 동작 또는 요점
3. **타깃**: 누가 보는가 (예: 자취생, 육아맘, 계단이 무서워진 40대)
4. **영상 길이**: 사용자가 지정하지 않으면 아래 기준으로 추천하고 확인받는다:

| 목적/유형 | 추천 길이 | 이유 |
|---|---|---|
| 신제품 인지 (생소한 상품, 궁금증 훅) | 15-25초 | 짧을수록 완주율↑ → 노출 알고리즘 유리 |
| 판매 전환 (셀링포인트·시연 필요) | 30-45초 | sales 기본값. 문제-해결-증거를 담는 최소 길이 |
| 습관·동작 전달 (동작 1-3개) | 30-45초 | habit 기본값. 동작 1개당 7-10초가 필요 |
| 신뢰 구축 (비교·검증형, "사지 마세요" 류) | 45-60초 | 논증에 시간이 필요, 저장·공유 목적 |

- AI 생성 씬이 포함되면 씬 길이를 생성 모델의 클립 단위(통상 5초 내외)의 배수로 맞춘다 — 3초 씬을 위해 5초를 생성해 컷하는 식으로 계획
5. **톤**: 정보형 / 리뷰형 / 상황극형 / ASMR형 중 택1 (기본: sales=리뷰형, habit=정보형. 스타일 프로필이 있으면 프로필이 우선)

## 스크립트 구조 (유형별 필수 5단계)

references/hook-patterns.md를 먼저 읽고 훅 유형을 `H1`~`H8` ID로 고른다. 스타일 프로필이 있으면 프로필의 훅 유형·리듬·톤이 우선한다.

### sales — 판매형 5단계

| 구간 | 시간 | 역할 |
|------|------|------|
| 훅(Hook) | 0-3초 | 스크롤 정지. 질문·반전·숫자·비포애프터 중 하나 |
| 문제 제기 | 3-10초 | 타깃의 페인포인트를 1문장으로 공감 |
| 해결 제시 | 10-25초 | 상품 등장 + 셀링포인트 최대 2개만 (3개 이상 금지) |
| 증거 | 25-35초 | 시연·비교·리뷰 수치 중 하나 |
| CTA | 마지막 3-5초 | 행동 지시 1개만 ("프로필 링크", "댓글에 링크") |

### habit — 습관·정보형 5단계

| 구간 | 시간 | 역할 |
|------|------|------|
| 훅(Hook) | 0-3초 | 증상 호명·통념 반전·동작 정점 중 하나 |
| 통념 깨기 | 3-8초 | "○○ 때문인 줄 알았는데 사실은 ○○" — 왜 지금까지 안 됐는지 |
| 방법 제시 | 8-28초 | **동작 최대 3개.** 동작마다 [이름 → 횟수·시간 → 주의 1줄] 3요소를 반드시 갖춘다 |
| 근거·주의 | 28-33초 | 왜 그런지 한 줄(메커니즘) + **안전 주의 문구 1개 이상 필수** |
| 실행 CTA | 마지막 3-5초 | **실행 유도 1개**("오늘 한 번만", "저장해두고 아침에"). 구매·제휴 링크 금지 |

- 동작 1개짜리 습관형이면 방법 제시를 짧게 잡고 근거·주의를 늘린다. 동작을 억지로 3개로 채우지 않는다
- 습관형은 "해결 제시"에 상품을 끼워 넣지 않는다. 제품을 소개하고 싶으면 별도 편으로 분리하고, 이 편에서는 예고만 한다

## 씬 시간 확정 (나레이션 실측 기준 — 필수)

**씬 시간은 나레이션 길이가 정한다. 그 반대가 아니다.** 스토리보드와 조립 단계는 여기서 확정한 시간을 그대로 받아쓴다. 이 순서를 뒤집으면 조립 단계에서 배속(atempo)으로 억지 보정하게 되고 나레이션 톤이 부자연스러워진다.

절차:

1. 구간별 나레이션 문장을 먼저 확정한다
2. 각 문장의 **음절 수를 세어 예상 길이를 계산한다** — 한국어 쇼츠 나레이션은 초당 약 4.5음절
   ```
   예상 초 = 음절수 ÷ 4.5 + 0.4   (0.4초는 문장 앞뒤 호흡)
   예: "계단 내려갈 때 무릎 시큰한 분" = 15음절 → 15÷4.5+0.4 ≈ 3.7초
   ```
3. 씬 시간을 이 예상 길이 이상으로 잡는다. 목표 총 길이를 넘기면 **씬을 늘리지 말고 문장을 줄인다**
4. 산출물에 씬별 [음절수 → 예상 초 → 배정 초]를 표로 남긴다 — 스토리보드·조립이 이 표를 근거로 삼는다
5. TTS를 실제로 생성한 뒤에는 **실측 길이로 이 표를 갱신한다.** 실측과 배정의 차이가 ±5%를 넘으면 배속이 아니라 씬 시간이나 문장을 고친다

## 출력 형식

```
🎬 [주제] 쇼츠 스크립트 (총 XX초)
content_type: sales | habit
훅 패턴: H3 (문제 직격형)

[0:00-0:03] 훅
  나레이션: "..."
  자막: "..."

[0:03-0:10] 문제
  ...
(이하 동일 형식)

📐 씬 시간표
| 구간 | 나레이션 음절 | 예상 초 | 배정 초 |
|---|---|---|---|
| 훅 | 15 | 3.7 | 4.0 |
```

- 나레이션과 화면 자막을 반드시 분리해서 쓴다 (쇼츠는 무음 시청 비율이 높아 자막이 독립적으로 이해돼야 함)
- 나레이션은 구어체, 한 문장 최대 15자 호흡으로 끊는다
- 훅은 항상 2안 제시하고 사용자가 고르게 한다
- 씬 시간표는 생략하지 않는다 — 다음 두 스킬의 입력이다

## 금지사항

- "안녕하세요 여러분" 류의 인사로 시작 금지 (훅 낭비)
- 셀링포인트·동작 나열식 구성 금지 (하나의 스토리라인 유지)
- 과장·허위 표현 금지: "최고", "1위", "100% 효과" 등 표시광고법 위험 표현은 쓰지 않고, 쓰게 되면 근거 필요함을 사용자에게 고지
- (habit) 의료 단정 금지: "치료", "낫는다", "예방한다" — 브리프의 대체 표현을 쓴다
- 이모지는 출력 구분용 외 나레이션·자막에 남용 금지

## [진단 모드] 기존 스크립트·쇼츠 채점

입력: 스크립트 텍스트, 또는 올린 쇼츠의 내용 묘사/스크린샷 (+선택: 조회수·완주율 등 성과 지표)

**채점 전에 content_type을 먼저 판별한다.** 구조·CTA 항목의 기준이 유형별로 다르다.

**채점표 (100점)** — 생성 규칙을 그대로 뒤집은 체크리스트:

| 항목 | 배점 | 기준 |
|---|---|---|
| 훅 (0-3초) | 30 | 인사말 시작 -15 / 훅 패턴 H1~H8 중 하나에 해당 +15 / 첫 문장이 타깃·문제·반전 중 하나를 담음 +15 |
| 구조 | 20 | 유형별 5단계 충족 여부, 빠진 단계당 -5 (sales=훅-문제-해결-증거-CTA / habit=훅-통념깨기-방법-근거주의-실행CTA) |
| 포인트 절제 | 15 | (sales) 셀링포인트 2개 이하 15 / 3개 10 / 4개 이상 0 · (habit) 동작 3개 이하 15 / 4개 이상 0 |
| 증거 구간 | 15 | (sales) 시연·수치·리뷰 중 하나 존재 15 / 주장만 있음 0 · (habit) 메커니즘 한 줄 + 안전 주의 문구 둘 다 있어야 15, 하나만 8, 없으면 0 |
| CTA | 10 | 행동 지시 1개 명확 10 / 없거나 2개 이상 0-5. (habit) CTA가 구매 유도면 0 (유형 위반) |
| 자막·규격 | 10 | 나레이션-자막 분리, 안전영역·길이 매트릭스 부합 |
| 법규 (감점 전용) | -30까지 | 브리프 금지 표현 발견 시 건당 -10, 발견 즉시 명시. (habit)은 의료 단정 표현이 대상 |

**출력 형식**:
1. 판별한 content_type + 총점 + 항목별 점수 표
2. **최우선 수정 1개** (점수 낙폭이 가장 큰 항목) + 구체적 교체안 (예: "훅을 H3으로: '...'")
3. 수정 2-3순위 간단 제시
4. 성과 지표를 받았으면: 점수와 지표의 연결 해석 (완주율 낮음 ↔ 훅·길이 문제)
5. 마무리 제안: "수정 반영한 새 버전을 생성 모드로 만들어드릴까요?"

- 점수는 근거 없이 주지 않는다 — 각 항목에 해당 대목을 인용해 판정 이유를 붙인다
- 진단만 요청받았으면 재작성을 임의로 하지 않는다
