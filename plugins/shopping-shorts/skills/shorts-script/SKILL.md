# 쇼핑쇼츠 스크립트 작성

유튜브 쇼츠용 상품 판매 스크립트를 만든다. 목표는 "3초 안에 잡고, 30초 안에 팔고, 마지막에 행동시키기".

## 모드 판별 (가장 먼저)

| 모드 | 발동 조건 | 동작 |
|------|----------|------|
| 생성 (기본) | 새 스크립트 요청 | 아래 0단계부터 진행 |
| 진단 | 기존 스크립트·쇼츠를 주며 평가/개선 요청 ("진단해줘", "조회수가 안 나와", "뭐가 문제야") | 맨 아래 [진단 모드] 절차로 |

## 카테고리 브리프 적용 (생성 모드 공통)

상품을 파악하면 카테고리(뷰티/건강식품/전자/식품/일반)를 판별하고 **references/category-briefs.md**의 해당 브리프를 읽어 적용한다:
- 훅 우선순위·씬 아이디어·증거 구간 구성은 브리프가 기본 규칙보다 우선
- 브리프의 금지/조건부 표현은 절대 규칙 — 위반 표현이 필요해 보이면 안전 대체 표현을 쓰고 사유를 사용자에게 고지
- 건강식품 카테고리는 산출 후 금지 표현 자체 점검 1회 필수

## 0단계: 레퍼런스 확인 (필수 질문)

작업 시작 전에 반드시 먼저 묻는다:

> "참고할 레퍼런스가 있나요? ① **판매하시는 제품 자료** (실사진·상세페이지·패키지) ② **유사 제품이나 사용 장면 자료** (경쟁 제품, 제품 쓰는 상황 이미지) ③ **벤치마킹할 쇼츠 영상** (링크·스크린샷) — 있는 것만 주시면 됩니다. 없으면 기본 스타일로 진행해요."

①은 제품의 정답지(형태 보존·생성 소스), ②는 장면 영감(배경·상황만 참고), ③은 편집 문법 참고로 역할이 다르다. 받은 자료가 어느 쪽인지 애매하면 반드시 확인한다.

레퍼런스를 받으면 **references/reference-analysis.md**의 절차대로 분석해 스타일 프로필을 만들고, 사용자 확인 후 이후 전 단계에 적용한다. 비주얼 레퍼런스(상품 사진)는 shorts-storyboard 단계의 AI 영상 생성 소스로 넘긴다.

## 입력 확인

사용자에게 아래 정보를 확인한다. 없으면 물어보되, 상품 URL이 있으면 웹서치/페치로 직접 조사해 채운다.

1. **상품**: 이름, 카테고리, 가격대
2. **핵심 셀링포인트**: 최대 3개 (없으면 리뷰·상세페이지에서 추출)
3. **타깃**: 누가 사는가 (예: 자취생, 육아맘, 캠핑족)
4. **영상 길이**: 사용자가 지정하지 않으면 아래 기준으로 추천하고 확인받는다:

| 목적/상품 유형 | 추천 길이 | 이유 |
|---|---|---|
| 신제품 인지 (생소한 상품, 궁금증 훅) | 15-25초 | 짧을수록 완주율↑ → 노출 알고리즘 유리 |
| 판매 전환 (셀링포인트·시연 필요) | 30-45초 | 기본값. 문제-해결-증거를 담는 최소 길이 |
| 신뢰 구축 (비교·검증형, "사지 마세요" 류) | 45-60초 | 논증에 시간이 필요, 저장·공유 목적 |

- AI 생성 씬이 포함되면 씬 길이를 생성 모델의 클립 단위(통상 5초 내외)의 배수로 맞춘다 — 3초 씬을 위해 5초를 생성해 컷하는 식으로 계획
5. **톤**: 정보형 / 리뷰형 / 상황극형 / ASMR형 중 택1 (기본: 리뷰형, 스타일 프로필이 있으면 프로필이 우선)

## 스크립트 구조 (필수 5단계)

references/hook-patterns.md를 먼저 읽고 훅 유형을 고른다. 스타일 프로필이 있으면 프로필의 훅 유형·리듬·톤이 우선한다.

| 구간 | 시간 | 역할 |
|------|------|------|
| 훅(Hook) | 0-3초 | 스크롤 정지. 질문·반전·숫자·비포애프터 중 하나 |
| 문제 제기 | 3-10초 | 타깃의 페인포인트를 1문장으로 공감 |
| 해결 제시 | 10-25초 | 상품 등장 + 셀링포인트 최대 2개만 (3개 이상 금지) |
| 증거 | 25-35초 | 시연·비교·리뷰 수치 중 하나 |
| CTA | 마지막 3-5초 | 행동 지시 1개만 ("프로필 링크", "댓글에 링크") |

## 출력 형식

```
🎬 [상품명] 쇼핑쇼츠 스크립트 (총 XX초)

[0:00-0:03] 훅
  나레이션: "..."
  자막: "..."

[0:03-0:10] 문제
  ...
(이하 동일 형식)
```

- 나레이션과 화면 자막을 반드시 분리해서 쓴다 (쇼츠는 무음 시청 비율이 높아 자막이 독립적으로 이해돼야 함)
- 나레이션은 구어체, 한 문장 최대 15자 호흡으로 끊는다
- 훅은 항상 2안 제시하고 사용자가 고르게 한다

## 금지사항

- "안녕하세요 여러분" 류의 인사로 시작 금지 (훅 낭비)
- 셀링포인트 나열식 구성 금지 (하나의 스토리라인 유지)
- 과장·허위 표현 금지: "최고", "1위", "100% 효과" 등 표시광고법 위험 표현은 쓰지 않고, 쓰게 되면 근거 필요함을 사용자에게 고지
- 이모지는 출력 구분용 외 나레이션·자막에 남용 금지

## [진단 모드] 기존 스크립트·쇼츠 채점

입력: 스크립트 텍스트, 또는 올린 쇼츠의 내용 묘사/스크린샷 (+선택: 조회수·완주율 등 성과 지표)

**채점표 (100점)** — 생성 규칙을 그대로 뒤집은 체크리스트:

| 항목 | 배점 | 기준 |
|---|---|---|
| 훅 (0-3초) | 30 | 인사말 시작 -15 / 훅 패턴 8종 중 하나에 해당 +15 / 첫 문장이 타깃·문제·반전 중 하나를 담음 +15 |
| 구조 | 20 | 5단계(훅-문제-해결-증거-CTA) 충족 여부, 빠진 단계당 -5 |
| 셀링포인트 절제 | 15 | 2개 이하 15 / 3개 10 / 4개 이상 0 (나열식 감점) |
| 증거 구간 | 15 | 시연·수치·리뷰 중 하나 존재 15 / 주장만 있음 0 |
| CTA | 10 | 행동 지시 1개 명확 10 / 없거나 2개 이상 0-5 |
| 자막·규격 | 10 | 나레이션-자막 분리, 안전영역·길이 매트릭스 부합 |
| 법규 (감점 전용) | -30까지 | 카테고리 브리프 금지 표현 발견 시 건당 -10, 발견 즉시 명시 |

**출력 형식**:
1. 총점 + 항목별 점수 표
2. **최우선 수정 1개** (점수 낙폭이 가장 큰 항목) + 구체적 교체안 (예: "훅을 패턴 ③으로: '...'")
3. 수정 2-3순위 간단 제시
4. 성과 지표를 받았으면: 점수와 지표의 연결 해석 (완주율 낮음 ↔ 훅·길이 문제)
5. 마무리 제안: "수정 반영한 새 버전을 생성 모드로 만들어드릴까요?"

- 점수는 근거 없이 주지 않는다 — 각 항목에 해당 대목을 인용해 판정 이유를 붙인다
- 진단만 요청받았으면 재작성을 임의로 하지 않는다

## 다음 단계 (체이닝)
