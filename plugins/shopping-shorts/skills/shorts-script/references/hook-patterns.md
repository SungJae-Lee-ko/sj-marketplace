# 쇼핑쇼츠 훅 패턴 8종

훅은 0-3초 안에 스크롤을 멈추게 하는 장치다. 콘텐츠 유형과 상품 유형에 맞는 패턴을 고른다.

**참조 규칙**: 다른 문서(category-briefs.md 등)에서 훅을 가리킬 때는 **반드시 `H1`~`H8` 고정 ID로 참조한다.** 목록 순번("④", "4번")으로 참조하지 않는다 — 패턴을 추가하거나 순서를 바꾸면 참조가 조용히 어긋난다. ID는 한 번 부여되면 바뀌지 않으며, 새 패턴은 H9부터 뒤에 붙인다.

| ID | 이름 | 한 줄 |
|---|---|---|
| H1 | 반전형 | 예상을 깨는 한 마디 |
| H2 | 숫자·비교형 | 두 값을 나란히 놓아 격차를 보여줌 |
| H3 | 문제 직격형 | 페인포인트를 정면으로 호명 |
| H4 | 비포애프터형 | 화면이 먼저 말함 |
| H5 | 금지·경고형 | 사지 마세요 / 하지 마세요 |
| H6 | 궁금증 유발형 | 이게 뭔지 궁금하게 만듦 |
| H7 | 타깃 호명형 | "○○인 사람만 보세요" |
| H8 | 시연 선공개형 | 가장 임팩트 있는 장면을 맨 앞에 |

---

## H1. 반전형
"이거 그냥 텀블러 아니에요" → 예상을 깨는 한 마디
- 적합: 기능이 숨어있는 상품, 다용도 상품
- 습관형 변형: 통념 뒤집기 — "무릎은 쉬면 낫는 게 아니에요"

## H2. 숫자·비교형
"3만원 vs 30만원, 차이 몰라보면 개이득"
- 적합: 가성비 상품, 대체재가 비싼 상품
- 습관형 변형: 시간·횟수 대비 — "하루 3분 vs 병원 3개월"

## H3. 문제 직격형
"설거지하다 손목 나가본 사람만 보세요"
- 적합: 페인포인트가 명확한 생활용품
- 습관형 변형: 증상 호명 — "계단 내려갈 때 무릎 시큰한 분"

## H4. 비포애프터형
(화면이 먼저 말함) 지저분한 책상 → 3초 후 정리된 책상
- 적합: 정리·청소·뷰티 등 시각 변화가 큰 상품
- 습관형 변형: 자세 교정 전후, 동작 가동 범위 전후

## H5. 금지·경고형
"이 프라이팬, 아직 사지 마세요"
- 적합: 구매 전 체크포인트가 있는 상품 (신뢰형 채널)
- 습관형 변형: 흔한 잘못된 동작 경고 — "이 스트레칭, 무릎엔 독입니다"

## H6. 궁금증 유발형
"택배 기사님이 이게 뭐냐고 물어봤어요"
- 적합: 생소한 신상품, 아이디어 상품

## H7. 타깃 호명형
"자취 5년차가 진심으로 아까워하는 소비"
- 적합: 타깃이 좁고 명확한 상품
- 습관형 변형: 연령·상황 호명 — "40 넘고 나서 계단이 무서워졌다면"

## H8. 시연 선공개형
(가장 임팩트 있는 시연 장면을 맨 앞에 배치)
- 적합: 성능이 눈으로 보이는 상품 (청소기, 칼, 접착제)
- 습관형 변형: 동작 정점 프레임을 먼저 — 벽 스쿼트 최저점부터 시작

## 선택 규칙

**판매형(sales)**
- 시각 임팩트가 있으면 H4 또는 H8 우선
- 페인포인트가 강하면 H3 또는 H7
- 신상품·저인지도 상품이면 H1 또는 H6

**습관·정보형(habit)**
- 증상·통증이 명확하면 H3 또는 H7
- 흔한 오해를 깨는 주제면 H1 또는 H5
- 동작이 눈에 보이면 H4 또는 H8

- 유형과 무관하게 **항상 서로 다른 패턴 2안을 제시**하고 사용자가 고르게 한다
