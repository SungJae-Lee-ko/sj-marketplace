# 쇼핑쇼츠 훅 패턴 8종

훅은 0-3초 안에 스크롤을 멈추게 하는 장치다. 상품 유형에 맞는 패턴을 고른다.

## 1. 반전형
"이거 그냥 텀블러 아니에요" → 예상을 깨는 한 마디
- 적합: 기능이 숨어있는 상품, 다용도 상품

## 2. 숫자·비교형
"3만원 vs 30만원, 차이 몰라보면 개이득"
- 적합: 가성비 상품, 대체재가 비싼 상품

## 3. 문제 직격형
"설거지하다 손목 나가본 사람만 보세요"
- 적합: 페인포인트가 명확한 생활용품

## 4. 비포애프터형
(화면이 먼저 말함) 지저분한 책상 → 3초 후 정리된 책상
- 적합: 정리·청소·뷰티 등 시각 변화가 큰 상품

## 5. 금지·경고형
"이 프라이팬, 아직 사지 마세요"
- 적합: 구매 전 체크포인트가 있는 상품 (신뢰형 채널)

## 6. 궁금증 유발형
"택배 기사님이 이게 뭐냐고 물어봤어요"
- 적합: 생소한 신상품, 아이디어 상품

## 7. 타깃 호명형
"자취 5년차가 진심으로 아까워하는 소비"
- 적합: 타깃이 좁고 명확한 상품

## 8. 시연 선공개형
(가장 임팩트 있는 시연 장면을 맨 앞에 배치)
- 적합: 성능이 눈으로 보이는 상품 (청소기, 칼, 접착제)

## 선택 규칙
- 시각 임팩트가 있으면 4번 또는 8번 우선
- 페인포인트가 강하면 3번 또는 7번
- 신상품·저인지도 상품이면 1번 또는 6번
- 항상 서로 다른 패턴 2안을 제시할 것
