# 레퍼런스 분석 → 스타일 프로필 추출

사용자가 준 레퍼런스를 분석해 "스타일 프로필"을 만들고, 이후 모든 산출물(스크립트·스토리보드·발행 키트)에 일관 적용한다.

## 레퍼런스 3분류 (역할이 다르므로 반드시 구분해서 받는다)

레퍼런스를 받을 때 아래 3종 중 어디에 속하는지 확인하고, 애매하면 사용자에게 묻는다:
"이 자료는 ① 판매하시는 제품 자체인가요, ② 참고하고 싶은 유사 제품/사용 장면인가요?"

### A. 제품 자료 (Identity — 판매 중인 내 제품)
받는 형태: 상품 실사진, 상세페이지 이미지, 브랜드 로고, 패키지 사진
- **역할**: 영상 속 제품의 "정답지". 형태·색·로고·패키지가 이 자료와 일치해야 한다
- **사용처**: AI 영상 생성 시 영상 모델의 **제품 참조 입력**(image_references·start_image)으로 직접 전달하는 유일한 자료. 이미지 모델로 A를 재생성한 스틸을 중간에 끼우지 않는다 (재생성 통과가 늘수록 제품이 왜곡됨)
- **규칙**: 프롬프트로 제품 형태를 재묘사하지 않는다. 동작·카메라·조명·배경만 지시한다

#### 생성에 좋은 A자료 (받을 때 한 번 안내)

AI 생성 정확도는 A자료 품질이 결정한다. **3~5장이 최적** — 1장은 모델이 없는 면을 상상하게 만들고, 10장 이상은 참조 잡음만 늘어난다:

| 우선순위 | 컷 | 용도 |
|---|---|---|
| 필수 | 정면 (라벨이 정중앙, 선명하게) | 제품 identity 기준, 검수 대조 원본 |
| 강력 권장 | 좌 또는 우 측면 45도 | 카메라가 움직이는 샷에서 왜곡 억제 |
| 권장 | 상단(탑뷰) 또는 손에 들었을 때 각도 | 사용 장면 샷 |
| 있으면 좋음 | 라벨·캡 등 디테일 클로즈업 | 라벨 텍스트 재현 정확도 |

품질 조건:
- **원본 파일 그대로** (메신저 전송본은 압축돼 라벨이 뭉개짐 — 파일 앱·에어드랍으로)
- 밝고 균일한 조명, **흰/단색 배경** (누끼·컴포지팅 강등 단계 대비)
- **필터·색보정 없는 사진** — 보정된 색이 "정답"으로 참조돼 실물과 다른 제품이 나온다
- **영상에서 보여줄 각도는 반드시 A에 있어야 한다** — 씬 설계는 A에 있는 각도 안에서만 한다(없는 각도는 AI가 상상 생성하다 왜곡). 원하는 연출 각도가 없으면 추가 촬영을 요청하는 것이 왜곡 재생성 크레딧보다 싸다

#### A 자료를 받으면 판매 형태를 1회 확인한다 (검증이 아닌 자기 신고 기반)

> "이 제품은 ① 직접 만들거나 소유한 브랜드 제품인가요, ② 다른 브랜드 제품을 리셀·위탁판매 중인가요, ③ 제휴 마케팅(쿠팡파트너스 등)인가요?"

| 형태 | A 자료 사용 규칙 | 발행 키트 연동 |
|---|---|---|
| ① 자사 제품 | 모든 자산 자유 사용 | 기본 |
| ② 리셀·위탁 | **직접 촬영한 실물 사진만** A로 인정. 브랜드 공식 사진·상세페이지 이미지는 사용권 확인 전까지 소스로 쓰지 않는다 (저작권). 브랜드 로고가 크게 나오는 연출은 지양 | "판매자 제공 이미지 아님" 등 오해 소지 점검 |
| ③ 제휴 | 플랫폼 이미지 사용 약관을 사용자에게 확인 요청. AI로 제품을 재생성하는 것은 실물과 달라질 수 있어 제휴 규정 위반 소지 — 실촬영·공식 제공 소재 권장 | **제휴 수수료 표기 문구 필수 삽입** (shorts-publish-kit에 전달) |

- 확인은 제품당 1회만. 같은 대화에서 재확인하지 않는다
- 스킬은 소유권을 판정하지 않는다. 답변을 그대로 신뢰하되, 위 규칙과 리스크를 고지하는 것까지가 역할이다

### B. 상황 자료 (Context — 유사 제품·사용 장면)
받는 형태: 경쟁사/유사 제품 사진, 제품을 쓰는 상황 이미지(예: 캠핑장에서 쓰는 모습), 무드보드
- **역할**: 장면 설계의 영감. 구도·배경·소품·사용 시나리오·조명 무드를 빌려온다
- **사용처**: 씬의 배경/상황 설정, 프롬프트의 environment·mood·lighting 파라미터. **영상 형태의 B**는 타사 제품·로고가 크게 보이지 않는 경우에 한해 영상 모델의 모션·무드 참조(video_references)로 쓸 수 있다
- **금지**: B를 제품의 소스로 쓰지 않는다 — 제품의 정답지는 언제나 A. 유사 제품의 형태·로고·디자인 요소가 프롬프트나 생성 결과에 섞이면 안 된다 (타사 제품 노출 + 디자인 도용 위험). 타사 제품이 크게 보이는 B는 참조로 넘기지 말고 "배경·구도만 참고하고 제품은 내 제품으로 교체"를 명시한다

#### 생성에 좋은 B자료 (받을 때 한 번 안내)

- **1~2개면 충분**, 각 10~30초 — 원하는 손동작·컷 리듬·조명 무드가 담긴 구간 위주
- **타사 제품·로고가 크게 안 보이는 클립** (보이면 video_references로 못 쓰고 무드 텍스트 추출용으로 강등)
- 여러 무드가 섞인 긴 영상보다 **한 가지 무드로 일관된 짧은 클립**이 참조 효과가 좋다
- 세로 9:16이면 구도 참조까지 되므로 가장 좋다

### C. 스타일 레퍼런스 (Style — 벤치마킹할 쇼츠 영상)
받는 형태: 유튜브 쇼츠 URL, 채널명, 스크린샷, 또는 "이런 느낌" 텍스트 설명
- **역할**: 편집 문법의 참고. 훅 방식·컷 리듬·자막 톤·사운드 사용
- URL을 받으면 웹 페치로 제목·설명·댓글 반응을 확인한다 (영상 자체는 볼 수 없으므로, 화면 내용은 스크린샷이나 말 묘사를 요청한다: "그 영상 첫 3초에 뭐가 나오나요?")

## 스타일 추출 절차 (C 레퍼런스 → 프로필 필드)

입력 형태별로 아래를 순서대로 수행한다. 각 필드는 "근거 → 값" 형식으로 채우고, 근거가 없는 필드는 추측하지 말고 "기본값"으로 둔다.

**1. 스크린샷을 받았을 때 — 이미지에서 직접 읽는다:**
- 자막 스타일: 위치(상/중/하), 색·외곽선, 강조 방식(키워드만 색 변경? 전체 볼드?), 한 줄 글자 수
- 비주얼 톤: 배경(스튜디오/실생활/야외), 밝기, 색감(웜/쿨), 화면 속 손·얼굴 노출 여부
- 훅 유형: 첫 프레임 스크린샷이면 hook-patterns.md 8종과 매칭 (화면이 말하는지, 자막이 말하는지)

**2. URL만 받았을 때 — 페치 결과에서 읽는다:**
- 제목 → 훅 유형·나레이션 톤 추정 (반말/존댓말, 궁금증형/직격형)
- 댓글 상위 반응 → 시청자가 반응한 포인트 (여기가 이 영상의 진짜 강점 — 스크립트에서 재현할 요소)
- 화면 정보는 없으므로: 컷 리듬·자막·비주얼 필드는 사용자에게 3가지만 묻는다: ① 첫 3초에 뭐가 나오는지 ② 말이 많은 영상인지 자막 위주인지 ③ 배경이 어떤 느낌인지

**3. 텍스트 묘사만 받았을 때:**
- 묘사에서 채울 수 있는 필드만 채우고 나머지는 기본값 표기
- 컷 리듬은 직접 알 수 없으므로 톤에서 유도한다: 정보전달형 묘사 → 3-4초 컷, 임팩트·유머형 묘사 → 1.5-2.5초 컷

**4. 채널 단위로 받았을 때 (여러 영상):**
- 최근 영상 2-3개의 공통 패턴만 프로필에 넣는다 (한 영상에만 있는 요소는 제외 — 채널의 문법과 단일 영상의 우연을 구분)

## 스타일 프로필 양식 (분석 결과를 이 양식으로 정리해 사용자 확인)

```
📋 스타일 프로필
[제품 - A에서]
- 제품 아이덴티티: 형태·색·로고 요약 / 소스 이미지 지정
[장면 - B에서]
- 사용 상황: (예: 아침 출근 준비 / 캠핑 저녁)
- 배경·소품·무드: (예: 따뜻한 우드톤, 자연광)
[편집 - C에서]
- 훅 유형: (hook-patterns.md 8종 중 매칭)
- 편집 리듬: 컷 평균 X초 / 전환 스타일
- 나레이션 톤 / 자막 스타일 / 사운드
```
없는 항목은 기본 규칙으로 채우고 "기본값"이라고 표기한다.

## 적용 규칙

1. 프로필은 사용자 확인을 받은 뒤에만 적용한다 ("이 스타일로 갈까요?")
2. 확인된 프로필은 대화 내에서 유지하고, 스크립트→스토리보드→발행 키트 전 단계에 일관 적용한다
3. A(제품)와 B(상황)가 충돌하면 — 예: 상황 자료의 제품 색이 내 제품과 다름 — 항상 A가 이긴다. 제품의 진실은 A에만 있다
4. 레퍼런스가 없다고 하면 기본 규칙(SKILL.md)대로 진행하되, 첫 산출 후 "다음엔 제품 사진과 참고 쇼츠를 주시면 정확도가 올라간다"고 한 번만 안내한다
5. 레퍼런스 스타일과 기본 금지사항이 충돌하면(예: 레퍼런스가 과장 표현 사용) 금지사항이 우선하고, 그 사실을 사용자에게 알린다
6. 타인의 영상·제품은 참고까지만 — 대사·자막·제품 디자인을 복제하지 않는다
