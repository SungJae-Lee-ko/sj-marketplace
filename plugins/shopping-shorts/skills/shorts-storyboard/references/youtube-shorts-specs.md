# 유튜브 쇼츠 규격 데이터 시트 (2026 기준, 최종 검증 2026-08)

스토리보드·영상 생성·발행 키트가 공통으로 참조하는 수치. 여기 값과 산출물이 어긋나면 산출물이 틀린 것이다.

## 파일 규격

| 항목 | 값 | 비고 |
|---|---|---|
| 비율 | 9:16 세로 | 가로(16:9)는 3분 이하여도 일반 영상으로 분류됨. 1:1은 쇼츠 인정되나 상하 블랙바 |
| 해상도 | 1080×1920 (권장) | 4K 세로 업로드 가능하나 시청 대부분 1080p — 1080p가 효율 기준 |
| 최대 길이 | 3분 (180초) | 2024-10 확장. 단 오래된 가이드에 60초로 남아있음 주의 |
| 실무 권장 길이 | 60초 이하, 최적 20-30초 | 알고리즘은 완주율 가중 — 본 플러그인의 길이 매트릭스(15-60초)와 일치 |
| 포맷/코덱 | MP4, H.264 | |
| 프레임레이트 | 24-60fps (30fps 표준, 시연 컷은 60fps 고려) | |

## 자막 안전영역 (1080×1920 기준)

- **하단 약 300px**: 유튜브 UI(제목·채널·음악 정보)가 덮음 — 자막·핵심 정보 배치 금지
- **우측 약 120px**: 좋아요·댓글·공유 버튼 열 — 텍스트 침범 금지
- **상단 약 150px**: 기기별 크롭·상태바 영역 — 여유 확보
- 안전 결론: **핵심 자막은 세로 중앙~중하단(하단 300px 위), 좌측 정렬 우선**
- 본 플러그인의 "피사체는 상단 2/3" 규칙과 함께 적용

## 발행 관련 실무 규칙

- 썸네일: 데스크톱 업로드는 커스텀 썸네일 불가. **모바일 유튜브 스튜디오 앱에서 프레임 지정 가능** → 발행 키트의 "썸네일 프레임 지정"은 이 경로 안내
- 오디오: 쇼츠 오디오 라이브러리 곡은 3분 쇼츠에서도 **약 90초 제한(일부 곡 30·60초)** — 60초 초과 영상 기획 시 BGM 확인 필수
- #Shorts 해시태그: 제목·설명에 포함하면 쇼츠 인식에 도움 (본 플러그인은 설명란에 배치)
- AI 생성 클립 포함 시: 업로드 화면 "변경·합성된 콘텐츠" 공개 설정 체크

## 알고리즘 특성 (기획 판단용)

- 쇼츠 피드는 일반 영상과 별도 알고리즘, 완주율(시청 유지)이 핵심 신호
- 3분까지 허용돼도 완주율이 떨어지는 긴 쇼츠는 도달이 줄어드는 트레이드오프 — 길이 매트릭스의 상한 60초를 넘기려면 명확한 이유 필요
- 쇼츠 → 채널 롱폼 유입 연계 전략 유효

## 유지보수 노트

플랫폼 규격은 변동된다. 산출 시점에 6개월 이상 지난 값이 의심되면(특히 길이·수익화·표기 정책) 웹서치로 재확인 후 이 파일 기준을 갱신하라고 사용자에게 알린다.
