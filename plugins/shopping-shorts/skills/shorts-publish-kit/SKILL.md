# 쇼핑쇼츠 발행 키트 (유튜브 쇼츠)

영상 업로드 직전에 필요한 모든 텍스트 자산을 한 번에 만든다.

## 입력 확인 (먼저)

- **`content_type`** (`sales` | `habit`) — shorts-assemble 리포트 또는 스크립트 산출물에 있다. 없으면 영상 내용을 보고 판별하고 확인받는다
- **판매 형태** (sales인 경우) — 자사 판매 / 제휴 마케팅(쿠팡 파트너스 등) / 협찬·유료광고. **고지 요건이 여기서 갈리므로 애매하면 반드시 묻는다**
- AI 생성 클립 포함 여부 (shorts-video-gen을 거쳤으면 포함)

## 산출물 (5종 고정)

### 1. 제목 3안
- 각 40자 이내, 훅 문장과 겹치지 않게
- 3안의 방향을 다르게:
  - (sales) ① 검색형(상품명+키워드) ② 호기심형 ③ 타깃호명형
  - (habit) ① 검색형(증상·동작명+키워드, 예: "무릎 통증 스트레칭") ② 통념 반전형 ③ 타깃호명형
- "#shorts"는 제목에 넣지 않는다 (설명란으로)

### 2. 설명문
- 첫 줄: 영상 핵심 1문장 (검색 노출 영역이므로 핵심 키워드 포함)
- (sales) 상품 링크 자리 표시: `👉 상품 보러가기: [링크]`
- (habit) 링크 자리 대신 관련 편 안내: `▶ 함께 보면 좋은 영상: [링크]`
- 3-5줄 이내

**고지 요건 (아래 표대로 — 빠뜨리면 검수 FAIL)**

| 판매 형태 | 설명란 | 고정댓글 | 문구 |
|---|---|---|---|
| 제휴 마케팅 (쿠팡 파트너스 등) | **필수** | **필수** | "이 포스팅은 파트너스 활동의 일환으로 수수료를 제공받을 수 있습니다" |
| 유료광고·협찬 | **필수** | **필수** | "유료 광고 포함" (+ 유튜브 업로드 화면의 유료 프로모션 체크) |
| 자사 판매 | 권장 | 권장 | "자사 제품입니다" |
| habit (제휴·판매 없음) | 불필요 | 불필요 | — |

- 고지는 **설명란과 고정댓글 양쪽 모두**에 넣는다. 구매 링크가 실제로 클릭되는 자리는 고정댓글이므로 한쪽만으로는 실효가 없다
- 설명란 고지는 "더보기"를 누르지 않아도 보이도록 **첫 3줄 안에** 배치한다

### 3. 해시태그 세트 (10-15개)
- 구성 비율: 대형 키워드 3 + 중형 카테고리 5 + 니치/롱테일 5
- #shorts #쇼츠 는 기본 포함
- (habit) 증상·동작·연령대 태그를 니치에 배치 (예: #무릎통증 #실내운동 #4050운동)
- 상품·주제와 무관한 유행 태그 금지

### 4. 고정댓글 문안
- (sales) 구매 링크 + **제휴/광고 고지 문구(위 표)** + 자주 묻는 질문 1개 선답변
- (habit) 동작 요약 3줄(따라 하기 쉽게 텍스트로 재정리) + **안전 주의 문구** + 다음 편 예고
- 고정댓글은 링크가 클릭되는 자리다 — 고지 문구를 링크와 **같은 댓글 안에** 둔다

### 5. 업로드 체크리스트
(규격 세부는 shorts-storyboard/references/youtube-shorts-specs.md 참조)
- 썸네일 프레임 지정 (스토리보드의 몇 번 씬을 쓸지 — 모바일 유튜브 스튜디오 앱에서만 프레임 지정 가능함을 안내)
- 60초 초과 영상이면 쇼츠 오디오 라이브러리 곡 사용 제한(약 90초, 일부 30·60초) 확인
- 업로드 추천 시간대 (타깃 시청 패턴 기준 제안)
- 제휴·유료광고 고지가 설명란·고정댓글 **양쪽에** 들어갔는지 확인
- **AI 생성 클립이 포함된 영상이면(shorts-video-gen 사용 시): 유튜브 업로드 화면의 "변경·합성된 콘텐츠" 공개 설정 체크 안내**
- (habit) 안전 주의 문구가 영상 자막·고정댓글 양쪽에 있는지 확인
- 종료 후 첫 1시간 댓글 대응 리마인드

## 어조 규칙

- 제목·설명은 낚시성 과장 금지 ("충격", "경악" 등)
- (sales) 효능·효과 단정 표현은 근거 없이 쓰지 않는다 (건기식·화장품은 특히 주의를 사용자에게 고지)
- (habit) 의료 단정 금지 — 제목·설명에 "치료", "완치", "낫는다"를 쓰지 않는다. "관리", "도움", "완화에 좋다고 알려진" 등으로 대체

## 마무리

- 제목·설명·고정댓글 카피는 AI 어투 교정(슬롭 리뷰) 스킬이 설치된 환경이면 체이닝해 다듬는 것을 권장한다 (미설치면 생략)

체인 위상: **shorts-script → shorts-storyboard → shorts-video-gen(AI 생성 시) → shorts-assemble → shorts-publish-kit**

발행 키트까지 끝나면 **shorts-auditor** 검수를 제안한다 (스크립트·스토리보드·완성 영상·발행 키트 일괄 PASS/FAIL). 검수를 통과하면 전체 산출물(스크립트·스토리보드·완성 MP4·발행 키트)을 하나의 문서로 묶어 정리해줄지 사용자에게 제안한다.
