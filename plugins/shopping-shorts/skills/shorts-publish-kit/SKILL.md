# 쇼핑쇼츠 발행 키트 (유튜브 쇼츠)

영상 업로드 직전에 필요한 모든 텍스트 자산을 한 번에 만든다.

## 산출물 (5종 고정)

### 1. 제목 3안
- 각 40자 이내, 훅 문장과 겹치지 않게
- 3안의 방향을 다르게: ① 검색형(상품명+키워드) ② 호기심형 ③ 타깃호명형
- "#shorts"는 제목에 넣지 않는다 (설명란으로)

### 2. 설명문
- 첫 줄: 영상 핵심 1문장 (검색 노출 영역이므로 핵심 키워드 포함)
- 상품 링크 자리 표시: `👉 상품 보러가기: [링크]`
- 유료광고/협찬이면 "유료 광고 포함" 표기를 반드시 안내 (표시광고법 + 유튜브 정책)
- 판매 형태가 **제휴 마케팅**으로 확인된 경우(reference-analysis.md의 판매 형태 확인 결과): "이 포스팅은 파트너스 활동의 일환으로 수수료를 제공받을 수 있습니다" 류의 표기 문구를 설명문에 필수 포함
- 3-5줄 이내

### 3. 해시태그 세트 (10-15개)
- 구성 비율: 대형 키워드 3 + 중형 카테고리 5 + 니치/롱테일 5
- #shorts #쇼츠 는 기본 포함
- 상품과 무관한 유행 태그 금지

### 4. 고정댓글 문안
- 구매 링크 + 자주 묻는 질문 1개 선답변 형식

### 5. 업로드 체크리스트
(규격 세부는 shorts-storyboard/references/youtube-shorts-specs.md 참조)
- 썸네일 프레임 지정 (스토리보드의 몇 번 씬을 쓸지 — 모바일 유튜브 스튜디오 앱에서만 프레임 지정 가능함을 안내)
- 60초 초과 영상이면 쇼츠 오디오 라이브러리 곡 사용 제한(약 90초, 일부 30·60초) 확인
- 업로드 추천 시간대 (타깃 시청 패턴 기준 제안)
- 유료광고 표기 여부 확인
- **AI 생성 클립이 포함된 영상이면(shorts-video-gen 사용 시): 유튜브 업로드 화면의 "변경·합성된 콘텐츠" 공개 설정 체크 안내**
- 종료 후 첫 1시간 댓글 대응 리마인드

## 어조 규칙

- 제목·설명은 낚시성 과장 금지 ("충격", "경악" 등)
- 효능·효과 단정 표현은 근거 없이 쓰지 않는다 (건기식·화장품은 특히 주의를 사용자에게 고지)

## 마무리

전체 체인(스크립트 → 스토리보드 → 발행 키트)이 끝나면 산출물 3종을 하나의 문서로 묶어 정리해줄지 사용자에게 제안한다.
